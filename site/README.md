# Application development

[한국어](README.ko.md)

Use Node.js 22.13+ and npm. `npm ci` installs the committed lockfile, `npm run dev` starts the portable preview, `npm run build` builds the Worker, and `npm start` runs that production output locally. No API key is needed. The root [README](../README.md) is the project introduction.

Canonical content is in `content/research.json`, `content/media.json`, `content/regional-records.json`, `content/global-events.json`, `content/forecasts.json` and `content/localizations.json`. Read the actual filenames and schemas before editing. `public/data/wiki/` is generated by `scripts/import-huiji.py` from reviewed snapshots. Never overwrite forecast history or convert missing values into facts.

Run `npm run check`, `npm test`, `npm run validate:content` and `npm run build`. Content validation verifies references, date precision, bilingual copy and media files. The app uses browser-local language/watchlist storage; it has no app-owned user database. Production access is managed by hosting, not this local preference storage.

The checked-in `.openai/hosting.json` identifies the upstream Site and contains no credentials. Do not publish forks to that ID. Configure a new deployment using your own provider/account and preserve external license notices. Build output, local runtime state, environment files and original media belong outside Git. Keep `package.json` private to avoid accidental npm publication; GitHub visibility is independent.
