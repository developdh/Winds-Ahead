# GitHub 기반 공식 캘린더 점검

[English](../en/calendar-automation.md) · [현행 일정 정책](official-schedules.md)

GitHub를 콘텐츠 원본으로 유지합니다. 기존에 선택한 매일 오전 9시 America/New_York 점검의 시간과 알림 설정을 유지하며 새 예약·GPT API 서비스·자동 병합을 추가하지 않습니다. 2026년 10월 2일부터 운영자 출시 예상을 중단합니다.

1. AGENTS.md와 현행 정책을 읽고 등록된 중국·글로벌·한국어 공식 출처를 확인합니다. 필요하면 공식 한국어 카페 GM 공지 본문을 읽습니다.
2. 서버별 동일성·영어/한국어 명칭·획득처·가격·판매/교환/할인/이벤트 종료와 누락 사진을 함께 확인합니다. 서버 사실·커뮤니티 관찰·날짜 정밀도·미확인 시간대를 구분하고 실제 출시 근거 없이 지난 예고를 출시로 바꾸지 않습니다.
3. 근거가 있는 누락을 선제적으로 보완합니다. 새 공지가 없으면 현재 보상·다가오는 종료를 우선해 제한된 수의 빈 갤러리를 점검합니다. 해당 외관 사진을 직접 확인하고 사용 가능한 여성 외형을 우선하며 전체 원본·출처·미확인 재배포 권한을 기록합니다.
4. 출시 예상을 생성·수정·재활성화·게시하지 않습니다. 미발표 일정은 미정으로 두고 이전 예상과 철회 이력은 감사용으로 보존합니다. 예상 재검토일을 연장하지 않습니다.
5. 실제 변경이 있을 때 양언어 문서와 콘텐츠를 갱신하고 타입·테스트·콘텐츠·이력·빌드를 검증합니다. 리뷰 가능한 영어 PR을 생성하거나 기존 PR을 갱신한 뒤 릴리스와 기존 사이트 게시 절차를 완료합니다. 변경 없는 점검에는 PR이나 릴리스를 만들지 않습니다.
6. 조치할 변화가 없으면 조용히 종료하고 의미 있는 변경·완료·실패 또는 사용자 조치가 필요한 경우만 알립니다. 로컬 실행은 PC·앱·도구 접근·계정 한도의 영향을 받습니다.
