# 종료 일정과 회기 위키 사진 · 2026년 9월 28일

[English](../en/deadlines-wiki-2026-09-28.md) · [PR #33](https://github.com/developdh/Winds-Ahead/pull/33)

운영자가 판매·교환 종료 임박 표시를 승인하고 이전에 제공한 [회기 위키 외관 도감](https://yy16s.huijiwiki.com/wiki/外观)의 사진 보강을 요청했습니다. 예상·갤러리 갱신과 한 업데이트로 묶어 v0.2.8에 반영합니다.

## 종료 표시

- 공식 종료 일정 23건에 서버, 종료 종류, 시작일, 원문 종료값, 날짜 정밀도, 명시·미명시 시간대, 출처, 검토일을 보존합니다. 기존 검토한 글로벌 판매 조건은 새 출처 확인을 주장하지 않고 구조화했습니다. 9월 23일 글로벌·중국 본문과 9월 3일 중국 교환 공지는 다시 확인했습니다.
- 도감 카드는 현재 표시 중인 획득 정보의 서버에 맞춰 안내합니다. 로드맵·캘린더에는 서버별 7일 이내 마감 목록이 나타나고 예상 일정 전용 필터에서는 숨깁니다. 상세에서는 공지 기간이 지난 뒤에도 날짜·시간·출처를 볼 수 있습니다.
- 판매·교환·할인·추첨·이벤트 종료를 구분합니다. 흑선의 울림의 10월 10일 할인 종료를 판매 종료로 바꾸지 않습니다. 열화전혼의 충돌하는 날짜와 기간만 제시된 상품은 제외했습니다.
- UTC·UTC+8의 명시된 시각은 그대로 처리합니다. 분·날짜 단위와 시간대 미표기는 가능한 구간을 유지하고, 종료 여부가 모호한 동안에는 정확한 시각 확인을 안내합니다. 시간대 미표기는 UTC+14~UTC−12 범위로 보수적으로 처리하며 정확한 카운트다운을 만들지 않습니다. 화면의 시간은 매분 및 탭 복귀 시 갱신됩니다.
- 날짜 경과가 출시 확인이나 실제 판매 중이라는 판단으로 바뀌지 않습니다. 기존 가격과 지역별 상태는 유지합니다.

## 사진 보강

사진이 없던 **55개 외관에 위키 사진 55장**을 추가했습니다. 의상 7개, 무기 47개, 탈것 1개입니다. 앞서 추가한 공식 여성 사진 6장을 포함해 **전체 663장**, **외관 716개 중 455개에 사진**이 있습니다. 나머지는 사진 확인 중 상태를 유지합니다.

브라우저에서 이름이 붙은 항목·파일 페이지를 확인한 뒤 공개 원본을 내려받았습니다. 여성 전신, 무기 전체, 탈것 이미지를 직접 확인했고, 의상 대신 얼굴만 보이는 텍스처나 무관한 아이콘은 제외했습니다. 항목별 출처와 동일 외관 근거는 [사진 조사 기록](../research/2026-09-28-wiki-gallery-provenance.json)에 있습니다.

전체 원본은 갤러리에 보존합니다. 화면용 이미지에서만 바깥 투명 여백을 줄이고, 세로형 카드에는 가로로 긴 무기도 전체가 들어가게 배치합니다. 최적화한 WebP와 기존 지연 로딩을 사용합니다. 위키 사진은 커뮤니티 참고 자료로 표시하고 항목·원본 링크를 제공하며, 공식 출시 상태를 바꾸지 않습니다.

거위 사진 원본은 260×260으로 상세 설명에 해상도 한계를 명시했습니다. 나머지 새 이미지는 긴 변이 512~1024px입니다. 파일 설명은 게임 클라이언트에서 내보낸 텍스처라고 밝힙니다. **재사용 허가는 미확인**입니다. 위키 하단의 CC BY-NC-SA 3.0을 NetEase 게임 이미지의 이용허락으로 간주하지 않습니다. 이미지는 코드 라이선스 적용 대상에서 제외하며 출처 표기를 재배포 허가로 보지 않습니다.

## 검증

타입 검사, 도메인·미디어 테스트 44개, 콘텐츠·출처 검사, 예상 변경 이력 보존 검사, 배포용 Worker 빌드를 통과했습니다. 종료 테스트는 7일 경계, 서버 분리, UTC+8 종료, 날짜·미명시 시간대의 모호성, 잘못된 시간값, 충돌하는 날짜 제외를 확인합니다. 새 사진은 크기·용량 한도·정지 이미지·전체 원본 보존을 검사합니다.

앱 내 Chromium에서 서버 전환, 키보드로 마감 항목 상세 열기, 할인 종료 문구, 위키 갤러리·출처 링크, 도감 배지를 확인했습니다. 320·360·390·768·1024·1440 CSS px의 확인 화면에서 가로 넘침이 없었습니다. 실기기·Firefox/WebKit·글자 200% 확대·실사용 성능은 미검증입니다. 기존 큰 묶음 파일·향후 Vite 로더 경고는 남아 있습니다. 새 정기 작업·자동 병합은 추가하지 않았습니다.

새 사진의 저장 용량은 카드 1,395,400바이트, 선택 이미지 206,252바이트, 화면용 2,293,572바이트, 전체 이미지 2,392,316바이트입니다. 첫 화면 전송량이나 실사용 성능 측정값은 아닙니다.
