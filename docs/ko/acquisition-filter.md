# 획득처 필터와 외관 정정

[English](../en/acquisition-filter.md)

도감의 출시 서버 선택·날짜/이름 정렬 옆에 독립적인 **획득처 필터**를 추가합니다. 예를 들어 강호령만 고른 뒤 글로벌 최신 출시순으로 정렬할 수 있습니다. 상점, 공명·추첨, 음옥 상점, 강호령, 이벤트, 플레이·누적 보상, 기타 교환, 획득처 확인 중을 구분합니다.

기록된 획득 방식과 재화로 분류합니다. 가격이 없다고 무료 보상으로 판단하거나 과거 공지를 현재 판매 중이라는 뜻으로 쓰지 않습니다. 모든 서버에서는 어느 한 서버의 기록된 획득처가 일치하면 표시하며 카드도 그 서버의 획득처·가격을 보여줍니다. 중국 또는 글로벌 출시 필터를 고르면 획득처도 해당 서버에 한정합니다. 글로벌 필터에서 획득 조건이 미정이면 중국 조건으로 대신하지 않습니다. 중국 조건이 확인된 외관은 글로벌 조건이 없다는 이유만으로 전체 미확인으로 분류하지 않습니다.

선택값은 검색·종류·서버·정렬과 함께 URL의 `acquisition`에 남깁니다. 언어 전환, 팝업 탐색과 독립 상세 페이지의 돌아가기 링크에도 유지합니다. 알 수 없는 URL 값은 모든 획득처로 처리하며 초기화 시 획득처도 해제합니다. 모바일은 첫 줄에 개수·정렬, 다음 줄에 두 필터를 배치하고 조작 영역은 44px을 유지합니다. 기존 사진·영상의 지연 로딩 방식은 그대로 유지합니다.

[중국 공지](https://www.yysls.cn/news/official/20251224/37780_1278303.html)의 **焰卷残夜**는 얼굴이 드러난 붉은 천 의상과 금빛 짐승 어깨 장식입니다. 글로벌 [영어](https://www.wherewindsmeetgame.com/news/official/903update.html)·[한국어](https://www.wherewindsmeetgame.com/kr/news/official/903update.html) 포스터의 **Forged in Fire / 불길에 단련된 철골**은 얼굴을 가린 불꽃 투구 갑옷입니다. 서로 다른 의상입니다.
