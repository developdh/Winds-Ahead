# 도감 탐색

[English](../en/archive-browsing.md)

## 화면 내 상세 정보

도감이나 관심 목록의 카드를 일반 클릭하면 목록 위에 상세 팝업을 엽니다. 사진과 눌러서 재생하는 영상을 먼저 배치하고, 이름·출시 기록·획득 정보·위키 세트 구성을 아래로 이어 보여줍니다. 팝업은 하나의 영역으로 스크롤하며 닫기 버튼은 상단에 남습니다. 관련 외관은 같은 팝업 안에서 교체됩니다.

검색·분류·서버·정렬·더 불러온 항목·스크롤 위치를 유지합니다. 팝업을 열면 주소에 `item`을 추가하고, 뒤로 가기는 닫기, 앞으로 가기는 다시 열기로 동작합니다. 쿼리 주소로 직접 방문해도 도감을 떠나지 않고 닫을 수 있습니다. 기존 개별 상세 주소와 새 탭 열기는 유지하고, 팝업 상단에도 개별 페이지 링크를 둡니다.

선택한 큰 사진은 팝업을 열 때 불러옵니다. 같은 외관의 사진을 넘길 때 표시 영역 크기를 유지하며 별도 확대 갤러리도 사용할 수 있습니다. 재생 요청 전에는 영상 플레이어나 iframe을 만들지 않습니다. 팝업 닫기·다른 외관 선택·사진 전환·재생 영역 이탈 시 플레이어를 해제합니다. 새 전환 효과도 동작 줄이기 설정을 따릅니다.

## 필터와 정렬

서버와 정렬은 작고 어두운 선택 메뉴로 표시합니다. 키보드 이동, 선택 상태, 높이 44px의 항목을 제공하며 검색·분류·서버·정렬을 함께 유지합니다.

- 양쪽 서버를 합친 최신 출시순(기본값).
- 중국 최신 / 오래된 출시순.
- 글로벌 최신 / 오래된 출시순.
- 글로벌 일정 가까운순.
- 현재 언어의 표시 이름 오름차순 / 내림차순.

서버별 날짜 정렬은 해당 서버의 확인된 출시 기록을 사용합니다. 날짜 미정은 방향에 관계없이 뒤에 배치하고, 같은 날짜는 현재 언어의 이름과 고정 ID로 정렬합니다. 가까운 일정순은 공식 발표 또는 유효한 운영자 예상을 사용합니다. 월 단위 예상은 가능한 첫 날짜로 순서만 정하며 그 날짜를 출시일로 표시하지 않습니다. 서로 다른 재화·서버의 가격은 비교하지 않습니다.

## 간결한 정보와 남은 날짜

카드 획득처에서 중복 서버 접두어를 빼고, 출시 서버는 한 번만 표시합니다. 가격·획득처의 툴팁에는 근거 서버를 유지하며 상세 정보에서는 서버별 조건을 구분합니다. 위키 참고 항목에 가격을 지어 넣지 않습니다.

파란 달력 표시는 **글로벌 출시 예정**, 금색 별 표시는 **글로벌 출시 예상**입니다. 색 외에도 문구·아이콘을 구분합니다.

- 공식 날짜: `D-38`, 당일에는 `오늘`. 발표 날짜가 지났으면 `출시 확인 중`으로 바꾸며 자동으로 출시 사실을 주장하지 않습니다.
- 예상 기간: `D-118–D-132`처럼 범위를 유지하고 기간 안에서는 `예상 기간 중`으로 표시합니다.
- 월·버전 예상: 월·버전만 표시하고 특정 날짜의 카운트다운을 만들지 않습니다.
- 공식 근거가 우선입니다. 출시 완료·철회·대체된 예상·지난 기간·검토 기한이 지난 예상은 카운트다운에서 제외합니다.
- UTC 날짜끼리 비교하고 매분 및 화면 복귀 시 갱신합니다. 정확한 출시 시각 타이머가 아니며 원문에 없는 시간대를 추정하지 않습니다.

최초 도감 개선 시점에는 미래 공식 예고와 예상이 없었습니다. 이후 [9월 13일 출시 검토](release-roadmap.md)에서 미래 글로벌 공식 예고 1개와 근거가 제한적인 예상 기간 3개를 공통 자료에 추가했으며 도감 카운트다운에도 반영됩니다.

## 검증

도메인·미디어 검증 28개로 정렬, 미정 날짜, 당일 경계, 취소 공지, 복각, 예상 정밀도·만료·공식 우선순위와 기존 콘텐츠·미디어 규칙을 확인합니다. 게시 전 타입 검사와 콘텐츠 검증을 수행합니다.

최종 브라우저 확인과 배포 빌드 측정은 아래에 기록합니다. 앱 내 브라우저의 화면 크기 확인을 실제 기기나 Firefox/WebKit 검증으로 확대 해석하지 않습니다.

서버 선택은 모든 서버·중국 출시·글로벌 출시 세 개입니다. 기존 양쪽 서버 출시는 모든 서버에 통합하고 이전 `server=both` 주소도 모든 서버로 연결합니다. 카드의 양쪽 서버 출시 표시는 유지합니다.

## 공유

팝업 상단과 개별 상세 페이지에 공유 버튼을 둡니다. 작은 창에서 링크 복사를 제공하고 지원 기기에서는 시스템 공유창도 열 수 있습니다. 언어와 외관 ID만 남기며 보낸 사람의 필터·검색어는 공유 주소에 포함하지 않습니다. 받은 사람은 도감에서 해당 외관 팝업을 바로 엽니다. 클립보드 권한이 없으면 선택 가능한 주소를 직접 복사할 수 있습니다. 시스템 공유창 취소는 오류로 처리하지 않습니다.

## 브라우저 확인 · 2026년 9월 13일

앱 내 Chromium에서 한국어·영어 상세 팝업, 사진 화살표, 확대 갤러리와 Esc 복귀, 닫기와 포커스 복원, 뒤로·앞으로 가기, item 직접 링크, 필터·정렬 유지, 24→48개 확장 목록 유지, 요청 시 영상 생성 및 닫을 때 제거를 확인했습니다. 링크 복사 완료와 불필요한 조건을 뺀 주소를 확인했으며 다른 앱으로 메시지를 보내지는 않았습니다. 시스템 공유창의 최종 전송은 검증하지 않았습니다.

320·360·390·768·1024·1440px에서 팝업이 가로 넘침 없이 화면 안에 배치됐습니다. 팝업 너비는 각각 320·360·390·704·960·1000px이며 닫기 영역은 44px입니다. 영어 320px·한국어 390px 메뉴와 사진 우선 배치를 시각적으로 확인했습니다. 팝업 크기의 CSS 전환을 명시적으로 끄고 나가는 사진을 확대하지 않도록 구성했습니다.

실제 휴대폰·Firefox/WebKit·200% 확대·네트워크 제한·시스템 공유 대상·실시간 동작 줄이기 전환은 검증하지 않았습니다. 동작 줄이기 및 클립보드 실패 경로는 코드에서 검토했습니다.

## 빌드 측정

최종 배포 빌드의 전체 클라이언트 모듈은 지연 로딩 모듈을 포함해 로컬 gzip 409,068바이트입니다(이전 388,229바이트 대비 20,839바이트 증가). 가장 큰 도감 데이터 모듈은 gzip 169,078바이트, SiteApp 모듈은 54,700바이트입니다. 글꼴 서브셋 합계는 335,888바이트입니다. 이는 산출물 크기로 실제 이동별 전송량이나 현장 성능이 아니며 기존 전체 클라이언트 용량 목표 초과는 남아 있습니다. 사진·영상 파일은 추가하지 않았습니다. 타입 검사·검증 28개·콘텐츠 검증·배포 빌드를 통과했습니다.


## 데스크탑 팝업과 출시 상태 수정 · 2026년 9월 13일

배포용 CSS에서 팝업의 개별 `translate` 선언이 빠지고 공통 팝업의 세로 `-50%` 이동이 남았습니다. 1440×900에서 높이 828px인 팝업의 상단이 정상 36px 대신 −378px에 놓였습니다. 앞선 개발 화면의 크기 검증으로는 이 배포판 차이를 발견하지 못했습니다. 도감 팝업은 이제 화면 여백과 가로 자동 마진으로 배치하고, 사용하는 곳에 `translate-none`을 지정해 공통 가로·세로 중앙 이동을 제거합니다. 등장·퇴장 움직임은 배치와 분리하며 공통 팝업 부품은 수정하지 않았습니다.

로컬에서 배포판을 실행해 인앱 Chromium의 1920×1080, 1440×900, 1440×700, 390×844, 320×640 화면을 검증했습니다. 팝업 상단은 각각 43.2, 36, 28, 12, 12px였고 모두 화면 안에 위치했습니다. 닫기 영역은 44×44px를 유지합니다. 높이 700px 화면에서 긴 팝업을 내부 스크롤해도 닫기 버튼 상단은 37px에 유지됐습니다. 사진 전환, 중첩 갤러리, Escape, 항목 주소 직접 열기, 재열기, 닫은 뒤 초점 복귀도 확인했습니다. Windows 실기기, 실제 모바일 기기, Firefox/WebKit, 브라우저 확대 검증은 하지 않았습니다.

카드와 상세 정보는 날짜를 반영하는 동일한 서버 상태를 사용합니다. 메뉴에 **중국 출시 예정**, **글로벌 출시 예정**, **출시 확인 중**을 추가했습니다. 출시 필터에는 미래 일정과 확인 대기 예고를 포함하지 않습니다. 공식 예정일 당일에도 예정 상태를 유지하며, 지난 예고는 확인 대기가 되고 자동으로 출시되지 않습니다. 출시 근거가 있는 날짜 미상 기록은 출시 상태를 유지합니다. 근거가 없는 항목은 예정 필터에 들어가지 않습니다. 예상은 기존 금색, 공식 예정은 파란색, 확인 대기는 회색으로 구분하고 문구와 아이콘도 다르게 표시합니다.

보관된 공식 발췌를 검토해 **중국 출시로 직접 저장된 56건과 암묵적으로 출시 처리된 6건**을 바로잡았습니다. 기존 출처와 날짜 미정 상태는 [수정 이력](../research/2026-09-13-release-status-corrections.json)에 보존합니다. 이 과거 예고 62건에는 `confirmationPending`을 지정하고 **중국 출시 확인 중**으로 표시합니다. 새로 잡힌 미래 일정이나 현재까지 미출시라는 증거가 아닙니다. 게임 내 실시간 판매 여부를 확인한 것이 아니라 도감에 확보된 근거를 정정한 것입니다. 중명·천지명귀의 초기 예고는 [중국 공식 원문](https://www.yysls.cn/news/official/20250926/37780_1261910.html)도 다시 읽었습니다.

검토일 기준 현재 기록에는 확인된 중국 미래 날짜가 없어 중국 출시 예정 필터가 비어 있을 수 있습니다. 글로벌 출시 예정 필터에서는 기존 9월 16일 예고가 `D-3`으로 표시됩니다. 배포판에서 한국어 확인 대기 카드·상세 상태, 영어 확인 대기 문구, 모바일 메뉴, 글로벌 남은 일수를 확인했습니다. 타입 검사, 도메인·미디어 테스트 32개, 콘텐츠 검증, 배포 빌드를 통과했습니다. 폰트와 미디어는 그대로이며 새로 추가된 한글 글자가 없어 폰트 부분집합을 다시 만들지 않았습니다.
