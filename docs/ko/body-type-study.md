# 본문 서체 비교

[English](../en/body-type-study.md)

사용자는 SUIT와 Pretendard가 모두 어울리지 않아 더 다양한 비교를 요청했습니다. **선택: D · 고운 돋움.** 사용자는 기본 굵기의 고운 돋움 본문과 Noto Serif KR 제목 조합을 선택했습니다. 아래 지침으로 로컬 비교 주소 `/design/body-font-study.html`을 다시 열 수 있으며 소스와 라이선스를 유지한 서브셋은 배포 공개 경로 밖인 `site/design-studies/body-type/`에 보관합니다.

| 후보 | 가볍게 / 기본 | 출처 |
| --- | --- | --- |
| Wanted Sans | 350 / 400, 가변 | [공식 프로젝트](https://github.com/wanteddev/wanted-sans) |
| Spoqa Han Sans Neo | 300 / 400 | [공식 프로젝트](https://github.com/spoqa/spoqa-han-sans) |
| IBM Plex Sans KR | 300 / 400 | [공식 프로젝트](https://github.com/IBM/plex), Google Fonts 배포 |
| 고운 돋움 | 400 한 가지 | [Google Fonts 원본](https://github.com/google/fonts/tree/main/ofl/gowundodum) |

제목은 Noto Serif KR로 고정하고 본문만 바꿉니다. 한글·영문·날짜·숫자·실제 획득 정보를 같은 배치에서 살펴보고 아래에서는 네 서체를 동시에 비교합니다. 인상에 대한 설명은 디자인 판단이며 제작자가 주장한 사실이 아닙니다.

로컬 미리보기는 `index.html`을 `site/public/design/body-font-study.html`로, `fonts/`를 `site/public/design/body-fonts/`로 복사합니다. Git에서 제외된 공개 미리보기 폴더는 배포 패키징 전에 밖으로 옮겨야 합니다. 보관한 서브셋은 내부 이름을 바꾸고 원본 OFL 고지를 유지합니다. 선택 후 실제 사이트에서 다시 비교하고 최종 타이포그래피를 확정합니다.
