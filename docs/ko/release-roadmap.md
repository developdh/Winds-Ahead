# 출시 로드맵과 9월 13일 검토

[English](../en/release-roadmap.md) · [캘린더 유지관리](calendar-automation.md)

로드맵은 앞으로의 공식 예고와 유효한 운영자 예상 기간을 시간순으로 보여줍니다. 캘린더는 중국·글로벌의 과거 날짜 기록을 유지합니다. 전체·확정 일정·예상 일정을 선택하고 언어·서버·보기·월·종류를 URL에 보존합니다. 월이 지정된 기존 주소는 캘린더로 열립니다. 공식 예고는 파란색, 예상은 금색이며 문구와 아이콘도 구분합니다.

## 확인한 공식 예고

**Chilled Current / 枕寒流 / 침한류(임시명)**는 2026년 9월 16일 업데이트 후 출시 예정입니다. 9월 11일 게시된 [글로벌 공식 X 원문](https://x.com/WhereWindsMeet_/status/2098411248107028581)과 남녀 이미지 패널을 직접 읽었습니다. 이미지의 출시 날짜는 UTC 기준이며 본문의 종료 시각은 10월 15일 04:59 UTC+8입니다. 시작 시각은 추정하지 않습니다. 예정일이 지나도 추가 출처로 출시를 확인하기 전까지 **발표됨** 상태를 유지합니다.

남성 관, 수묵 산수 도포, 어깨·허리의 파란 붓꽃 장식이 [중국 강호령 공지](https://www.yysls.cn/news/official/20260807/37780_1310523.html)와 일치하고 양쪽 모두 강호령 의상으로 소개합니다. 중국 날짜는 8월 7일, 간격은 40일이며 다른 외관의 공통 지연 기간으로 사용하지 않습니다. 공식 영문명만 추가했고 한국어 이름은 임시명입니다. 가격과 보상 레벨은 미정입니다.

후보 출처는 [중국 6월 30일](https://www.yysls.cn/news/official/20260703/37780_1306509.html), [중국 7월 23일](https://www.yysls.cn/news/official/20260724/37780_1309060.html), 기존 검토한 [글로벌 9월 3일 업데이트](https://www.wherewindsmeetgame.com/news/official/903update.html)입니다. 연대학의 날짜는 6월 30일 표시 공지의 ‘이번 금요일’을 7월 3일로 해석한 문맥상 날짜입니다. 활의 중국 정확한 날짜는 미정으로 남겼으며 부채 날짜를 복사하지 않았습니다.

세 예상 모두 **근거 제한적**, 최초 변경이며 재검토일은 9월 16일입니다. 글로벌 출시·순서·가격·최종 도입 여부는 확정되지 않았습니다. 기간은 운영자 판단이며 통계적 신뢰구간이 아닙니다. 근거가 부족한 외관은 미정으로 남깁니다. 강남 기념 의상과 협업 외관에는 일반 상점 간격을 부여하지 않았습니다. 후보 3개는 현재 출처 장부에 확인된 글로벌 동일 외관 연결이 없지만, 모든 글로벌 공지에 없음을 완전히 증명한 것은 아닙니다.

미러에서 ‘Bane of Life’의 9월 16일 예고 단서를 찾았지만 원문과 중국 동일 외관을 확인하지 못해 확정 자료로 올리지 않았습니다. 중국·영문·한국어 공식 뉴스 목록을 확인했으며, 이름이 명시된 미래 중국 외관 출시는 이번 검토에서 확인하지 못했습니다. 이 수집 한계를 ‘앞으로 나올 공지가 전혀 없다’고 표현하면 안 됩니다.

## 유지관리와 검증

현재 Codex 작업에서 검토했고 세션의 정확한 모델 식별자는 노출되지 않습니다. 방법 버전은 `release-review-v1`입니다. 공식 원문을 읽고 획득 유형 안에서 동일성이 확인된 상품을 비교하며, 반례를 기록하고 넓은 기간 또는 미정을 선택한 뒤 영어·한국어 근거를 남깁니다. 별도 GPT API는 실행하지 않았습니다. 예상 작성 시각은 9월 13일 22:21:10 UTC이며 화면의 출처 확인 날짜는 `forecasts.reviewedAt`에서 가져옵니다.

기존 매일 점검 작업을 유지하며 중복 예약을 만들지 않았습니다. 공식 기록과 확인 날짜는 출처를 읽은 뒤 갱신합니다. 공개된 예상을 덮어쓰지 말고 변경 기록을 추가합니다. 캘린더·로드맵·도감 카운트다운은 기간 종료·검토 기한 경과·대체된 예상을 숨기고 공식 근거를 우선하며, 모든 예상 변경은 이력에서 볼 수 있습니다. 재검토일이 지나도 원래 기록은 삭제하지 않습니다.

로드맵은 기존 축소 이미지만 지연 로딩하며 영상 플레이어·외부 삽입·실시간 AI 호출을 추가하지 않습니다. 사진이 없는 경우를 처리하고 미정 예시는 6개만 렌더링하되 전체 도감으로 연결합니다. 공식 우선순위, 예정일 경과 후 미확인 상태, 취소, 복각, 검토 만료, 버전 정밀도를 검증합니다. 공개 전에 타입 검사·콘텐츠 검증·배포 빌드를 통과해야 합니다.
