# 출시 로드맵과 예상 검토

[English](../en/release-roadmap.md) · [캘린더 유지관리](calendar-automation.md)

로드맵은 앞으로의 공식 일정을 모두 먼저 표시하고, 그 뒤에 ‘예상 일정 · 운영자 예상 · 비공식’ 구역을 분리해 보여줍니다. 각 구역 안에서는 시간순이며 예상 기간의 시작이 빨라도 공식 일정 앞에 나오지 않습니다. 캘린더는 중국·글로벌의 과거 날짜 기록을 유지합니다. 전체·확정 일정·예상 일정을 선택하고 언어·서버·보기·월·종류를 URL에 보존합니다. 월이 지정된 기존 주소는 캘린더로 열립니다. 공식 예고는 파란색, 예상은 금색이며 문구와 아이콘도 구분합니다.

## 확인한 공식 예고

**Chilled Current / 枕寒流 / 침한류(임시명)**는 2026년 9월 16일 업데이트 후 출시 예정입니다. 9월 11일 게시된 [글로벌 공식 X 원문](https://x.com/WhereWindsMeet_/status/2098411248107028581)과 남녀 이미지 패널을 직접 읽었습니다. 이미지의 출시 날짜는 UTC 기준이며 본문의 종료 시각은 10월 15일 04:59 UTC+8입니다. 시작 시각은 추정하지 않습니다. 예정일이 지나도 추가 출처로 출시를 확인하기 전까지 **발표됨** 상태를 유지합니다.

남성 관, 수묵 산수 도포, 어깨·허리의 파란 붓꽃 장식이 [중국 강호령 공지](https://www.yysls.cn/news/official/20260807/37780_1310523.html)와 일치하고 양쪽 모두 강호령 의상으로 소개합니다. 중국 날짜는 8월 7일, 간격은 40일이며 다른 외관의 공통 지연 기간으로 사용하지 않습니다. 공식 영문명만 추가했고 한국어 이름은 임시명입니다. 가격과 보상 레벨은 미정입니다.

미러에서 ‘Bane of Life’의 9월 16일 예고 단서를 찾았지만 원문과 중국 동일 외관을 확인하지 못해 확정 자료로 올리지 않았습니다. 중국·영문·한국어 공식 뉴스 목록을 확인했으며, 이름이 명시된 미래 중국 외관 출시는 이번 검토에서 확인하지 못했습니다. 이 수집 한계를 ‘앞으로 나올 공지가 전혀 없다’고 표현하면 안 됩니다.

## 유지관리와 검증

현재 Codex 작업에서 검토했고 세션의 정확한 모델 식별자는 노출되지 않습니다. 방법 버전은 `release-review-v1`입니다. 공식 원문을 읽고 획득 유형 안에서 동일성이 확인된 상품을 비교하며, 반례를 기록하고 넓은 기간 또는 미정을 선택한 뒤 영어·한국어 근거를 남깁니다. 별도 GPT API는 실행하지 않았습니다. 예상 작성 시각은 9월 13일 22:21:10 UTC이며 화면의 출처 확인 날짜는 `forecasts.reviewedAt`에서 가져옵니다.

기존 매일 점검 작업을 유지하며 중복 예약을 만들지 않았습니다. 공식 기록과 확인 날짜는 출처를 읽은 뒤 갱신합니다. 공개된 예상을 덮어쓰지 말고 변경 기록을 추가합니다. 캘린더·로드맵은 재검토일이 지나도 기간이 남은 활성 예상을 ‘재검토 필요’와 함께 표시합니다. 기간 종료·철회·공식 발표로 대체된 예상은 숨깁니다. 도감 카운트다운은 재검토일이 지난 예상을 계속 제외하며, 모든 예상 변경은 이력에서 볼 수 있습니다. 재검토일이 지나도 원래 기록은 삭제하지 않습니다.

로드맵은 기존 축소 이미지만 지연 로딩하며 영상 플레이어·외부 삽입·실시간 AI 호출을 추가하지 않습니다. 사진이 없는 경우를 처리하고 미정 예시는 6개만 렌더링하되 전체 도감으로 연결합니다. 공식 우선순위, 예정일 경과 후 미확인 상태, 취소, 복각, 검토 만료, 버전 정밀도를 검증합니다. 공개 전에 타입 검사·콘텐츠 검증·배포 빌드를 통과해야 합니다.

완료 검증: 도메인·미디어 검증 30개, 타입 검사, 콘텐츠 검증과 배포 빌드를 통과했습니다. 브라우저에서 한국어 390px·영어 320px, 로드맵·캘린더 전환, 예상 필터, 월 경계 포함, 중국 전환 시 필터 초기화, 기존 월 지정 주소를 확인했습니다. 두 작은 화면에서 가로 넘침이 없었고 로드맵은 영상 요소를 만들지 않았습니다. 실제 모바일 기기와 현장 성능은 측정하지 않았습니다.

## 앞으로의 일정 표시 규칙

사용자 요청에 따라 예정일의 UTC 날짜가 지난 예고는 로드맵에서 숨깁니다. 이전에 ‘출시 여부 확인 중’으로 표시되던 항목도 포함합니다. 오늘과 미래의 예고는 계속 표시합니다. 과거 캘린더·출처 기록은 원래 상태를 유지하며, 지난 예고를 숨기는 것으로 출시가 확정되거나 공식 예고에 밀렸던 예상이 되살아나지 않습니다. 중국·글로벌 타임라인과 일정 종류 필터에 같은 규칙을 적용합니다.

이번 표시 변경은 타입 검사, 기존 도메인·미디어 테스트 32개, 콘텐츠 검증과 Worker 빌드를 통과했습니다. 9월 14일 UTC 기준 로컬 브라우저에서 글로벌 전체 5건(예고 2건·예상 3건), 확정 일정 2건, 중국 타임라인의 빈 상태를 확인했습니다. 날짜가 지난 글로벌 미확인 예고 2건은 표시되지 않았으며 언어를 바꿔도 확정 일정 필터가 유지됐습니다.

## 9월 20일 출처 검토

[영문](https://www.wherewindsmeetgame.com/news/official/920appearance.html)·[한국어](https://www.wherewindsmeetgame.com/kr/news/official/920appearance.html) 공지의 9월 20일 글로벌 외관 5종과 중국 9월 15~17일 공지의 외관 15종을 반영했습니다. 글로벌 시각은 05:00 UTC+8이며 한국어 원문은 시간대 없이 06:00로 표기합니다. 날짜 경과로 실제 출시를 확정하지 않습니다.

기존 예상 3건의 기간과 변경 이력은 유지했습니다. 모두 재검토일이 9월 16일이어서 숨겨졌으며 예상 기간 종료 때문이 아니었습니다. 이제 로드맵·캘린더에 재검토 표시와 함께 남습니다. 현영 시리즈 검·횡도 공지는 부채의 출시 순서를 확정하지 않습니다. 공식 X의 최신 글을 읽었으나 이전 글은 로그인 화면에 막혀 전체 검토는 아닙니다. [검토 기록](../research/2026-09-20-official-announcements.json)을 참고하세요.
