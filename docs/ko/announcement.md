**연운 외관 도감 ‘연운경’ 만들어봤음 (중섭·글섭 / 오픈소스)**

중섭에 나온 옷이랑 글섭 출시 정보를 한곳에서 보고 싶어서 **연운경 / Winds Ahead** 만들었음.

👉 https://windsahead.com

- 의상·헤어·무기·이펙트 사진, 영상 모아보기
- 가격·필요 재화·획득처, 중섭·글섭 출시 상태 확인
- 팝업으로 빠르게 비교하고 관심 외관 저장·공유
- 확정 일정과 예상 일정을 구분한 캘린더·로드맵

한국어/영어 지원하고 모바일에서도 볼 수 있음. 예상 일정은 공식 확정이 아니고, 아직 빈 사진이나 미확인 정보는 계속 채워가는 중.

**오픈소스 프로젝트라 누구나 컨트리뷰트 가능함.** 개발뿐 아니라 번역, 정보 수정, 출처 제보도 환영!

**이 프로젝트는 수익을 창출하지 않음.** 광고나 유료 기능 없이 운영하는 비영리 팬 프로젝트임.

GitHub: https://github.com/developdh/Winds-Ahead

틀린 정보나 불편한 점 있으면 알려주면 감사하겠음.
