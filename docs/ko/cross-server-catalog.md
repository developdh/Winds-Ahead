# 중국·글로벌 외관 전체 조사

[English](../en/cross-server-catalog.md)

2026년 9월 13일 확장은 무료 보상·장신구·탈것을 포함한 중국·글로벌 외관을 대상으로 합니다. 현재 수집 중입니다. 공식 공지 전체 목록은 조사할 출처의 목록이며, 양쪽 게임 클라이언트의 전체 외관 수를 보증하지 않습니다.

## 서버별 기록

카드에는 과거 출시 근거를 확인한 서버를 표시합니다. 서버 선택에서 중국·글로벌·양쪽 출시 항목을 고를 수 있습니다. 표시가 없는 서버는 미출시·전용이 아니라 확인 중입니다. 상세에서는 서버별 출처·적용 범위·확인일과 이름이 다른 외관을 연결한 근거를 따로 보여줍니다. 출시 기록은 현재 판매 여부를 뜻하지 않습니다. 발표와 출시, 날짜 미정과 정확한 날짜를 구분합니다.

`site/content/regional-records.json`에 확인한 서버 근거를 캘린더 이벤트와 분리해 기록합니다. 기존 중국 항목은 원출처 기록을 유지합니다. 글로벌에서 먼저 확인한 외관은 글로벌 출처를 사용하고 중국 날짜를 미정으로 둘 수 있습니다. 확인한 영어·한국어 공식명을 우선 표시하며 원명과 편의 이름도 검색할 수 있습니다. 중국 가격을 글로벌에 복사하지 않습니다.

## 수집 절차

공식 공지의 전체 목록을 읽고 외관 이름이 있는 절을 추출한 뒤, 연결된 게임 이미지를 확인하고 획득 조건과 서버 간 동일성을 검토해 등록합니다. 자동 추출 제목과 커뮤니티 도감은 검토 전까지 조사 후보로 유지합니다. 무기 변형·염색·헤어·체형 차이를 별도 의상으로 잘못 세지 않도록 항목의 정체를 확인합니다. 원본 미디어와 임시 OCR은 Git 밖에 두고 최적화한 정적 이미지와 출처만 기록합니다.

첫 화면은 24장만 표시하고 더 보기를 누르면 추가합니다. 도감 이미지는 정지 화면을 유지하고 영상은 눌러서 재생합니다. 자료가 늘어도 움직이는 썸네일이나 큰 갤러리 전체의 즉시 로드를 도입하지 않습니다.

## 진행과 검증

첫 구현은 서버 필터, 서버별 독립 근거, 글로벌 원출처 항목, 무료 보상 획득 방식을 추가합니다. 기반 작업 시점에 타입 검사와 날짜·미디어 테스트 21개가 통과했습니다. 전체 자료 범위, 실제 외관의 서버 간 연결과 최종 반응형 확인은 수집 묶음 이후 진행합니다. 전체 외관 수집이 완료됐다고 주장하지 않습니다.

## 첫 콘텐츠 반영 단위

2026년 9월 13일 외관 기록 431개, 정지 이미지 361개, 글로벌 기록 87개(날짜가 있는 출시 공지 60개·출시 보상 27개), 중국·글로벌 이미지 비교 연결 48개를 검증했습니다. 이 묶음은 공식 출처 144개를 참조합니다. 개별 이미지가 확인되지 않은 외관은 사진 확인 중으로 표시합니다. 과거 공식 공지는 외관의 존재 근거가 될 수 있으나 최초 출시일이나 현재 가격의 근거와는 구분합니다. 더 이른 글로벌 업데이트 목록도 다음 묶음으로 반영 중입니다.
