# 중국·글로벌 외관 도감

[English](../en/cross-server-catalog.md)

2026년 9월 13일 외관 기록을 40개에서 **545개**로 확대했습니다. 356개 기록에 **정지 참고 이미지 455개**가 연결되어 있습니다. 공식 자료에 근거한 중국 기록은 403개, 글로벌 기록은 215개이며 **73개의 서버 간 동일 외관**을 명칭이 붙은 이미지로 연결했습니다. 수치는 기록 개수이며 게임 내 고유 외관 총수를 인증하지 않습니다. 동일 외관 연결이 미확인인 기록은 분리되어 있을 수 있습니다.

## 포함 범위

의상·헤어·무기·이펙트·장신구(동물용임을 구분한 파트너 외관 포함)·탈것을 다룹니다. 글로벌 자료에는 상시 출시 보상 27개와 날짜가 있는 출시 기록 186개가 포함됩니다. 중국·글로벌의 가격·획득 조건·날짜·현재 판매 여부 제한을 구분했습니다. 카드에는 확인된 글로벌 획득 정보가 있으면 이를 우선 표시하고 가격 기준 서버를 함께 적습니다. 상세에서는 서버마다 출처를 확인할 수 있습니다. 확인 중은 미출시나 독점 출시라는 뜻이 아닙니다.

확인된 영어·한국어 공식 명칭을 우선 표시하고 중국 원명·편의 표기를 검색에 남깁니다. 한국어 명칭을 아직 대조하지 못한 초기 글로벌 기록은 확인한 영문 식별명을 유지합니다. 출시 보상 네 항목의 한국어 명칭 불일치, 영문 11월 14일·한국어 11월 15일로 다른 출시일, 불명확한 재화 표기를 보존했습니다. 시간대는 추정하지 않으며 5월 공지에서 명시한 UTC+8 시각은 근거 범위에 남겼습니다.

## 근거와 확인 범위

[출처 목록](../research/2026-09-13-inventory.json)에 중국 공지 색인 601개, 본문 분석 470개, 원시 명칭·분류 후보 565개, 글로벌 색인 64개, 커뮤니티 도감 단서 57개를 기록했습니다. 추출 후보 수가 게임 내 총 외관 수를 뜻하지 않습니다. 게시 기록에는 기본 공식 출처가 있으며 커뮤니티 캡처는 이미지 참고용으로만 사용하고 출시일·가격의 근거로 사용하지 않습니다. 개별 이미지가 없으면 다른 외관으로 채우지 않고 사진 확인 중으로 표시합니다. 원본·OCR은 Git 밖에 두고 최적화한 이미지와 출처만 저장합니다.

랜덤 상자·패키지와 개별 구성품을 구분했습니다. 우산 여섯 스타일과 장신구 세 구성품은 각각의 이미지를 사용하며 상자·패키지 가격을 개별 외관의 고정 가격으로 표시하지 않습니다. 의상과 헤어가 같은 영문명을 쓰는 Purple Dew 등은 두 기록을 유지합니다.

## 성능과 검토

첫 화면은 카드 24개만 표시하며 더 보기를 눌러 확장합니다. 썸네일은 파일당 최대 160 KB의 정지 WebP, 갤러리는 파일당 최대 2.5 MB입니다. GIF 원본은 한 장의 정지 화면으로 변환합니다. 자동 재생 영상이나 원격 프레임을 추가하지 않으며 기존 이펙트 영상은 눌러서 재생합니다. 재배포 권한 미확인 자료는 소유자 전용 비공개 참고 미리보기로 유지하며 이번 변경으로 공개 범위를 바꾸지 않습니다.

GitHub에는 서버별 자료 구조, 첫 431개 기록 묶음, 최종 검토를 구분해 남깁니다. 자료 형식·출처 연결, 도메인·미디어 테스트 21개, 타입 검사, 예상 이력 보존 검사, 배포 빌드를 통과했습니다. 앱 내 Chromium에서 중국·글로벌·양쪽 서버 필터, 공식명 검색, 언어 전환·뒤로 가기 상태, 사진 없는 헤어 상세를 확인했습니다. 도감·상세를 320·360·390·768·1024·1440px에서 확인하고 영문 카테고리의 가로 넘침을 수정했습니다. 배포 파일로 실행한 도감에서 카드 24개, 영상·프레임 0개, 깨진 로드 이미지 0개, 브라우저 오류 0개를 확인했습니다.

320px 화면에 보인 썸네일 네 장은 파일 합계 175,936바이트입니다. 네트워크나 Core Web Vitals 측정값이 아닌 파일 용량입니다. 글꼴 합계는 315,176바이트이며 지연 로딩을 포함한 전체 클라이언트 JavaScript는 gzip 합계 368,241바이트입니다. 전체 도감 데이터 묶음은 gzip 153,497바이트를 차지합니다. 초기 JavaScript 200KB 목표 달성을 인증하지 않으며 화면별 데이터 분리와 느린 네트워크 측정이 성능 후속 과제로 남습니다. 실제 iOS·Android 기기, Firefox·WebKit, 현장 INP, 저속 네트워크 검증은 수행했다고 주장하지 않습니다. 이번 확장이 게임 안의 모든 외관을 빠짐없이 수집했다는 인증은 아닙니다.
