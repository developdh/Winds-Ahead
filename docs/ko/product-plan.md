# 연운경 제품 기획 v0.1

[English](../en/product-plan.md) · [문서 목록](../../README.ko.md)

작성일: 2026-09-12 (America/New_York). 단계: 기획 초안. 아래 범위는 초기 제안이며 실제 게임 출시 예측 결과가 아닙니다.

## 1. 제품 정의

**Winds Ahead / 연운경(燕雲鏡)**은 글로벌 서버 이용자가 중국 서버에서 공개·출시된 외관을 살펴보고, 원하는 외관의 글로벌 출시 여부와 예상 시기를 이해하는 팬 도감입니다.

핵심 방문 목적은 세 가지입니다.

1. 중국 서버에서 본 외관을 찾아 사진·영상과 획득 방법을 확인한다.
2. 글로벌 출시가 확정됐는지, 예상이라면 어떤 근거인지 확인한다.
3. 관심 외관을 저장하고 다음 방문에 일정 변경을 확인한다.

일반 게임 공략이나 뉴스 전체를 다루지 않고 외관과 관련 일정에 집중합니다. 운영자는 초기에는 한 명이어도 관리할 수 있어야 합니다.

댓글·커뮤니티 게시판, 공개 파일 업로드, 과금 기대값 계산기, 비공개 유출 자료, 게임 계정 연동은 초기 범위에서 제외합니다. 알림 서비스나 자동 정기 수집은 이 기획만으로 생성하지 않습니다.

## 3. 사이트 구성

`{locale}`은 `ko` 또는 `en`입니다. `/`는 저장된 언어 선택 → 브라우저 언어 → 영어 순으로 안내합니다. 언어별 URL로 직접 접속하면 해당 언어를 유지합니다.

| 경로 | 화면 | 핵심 동작 |
| --- | --- | --- |
| `/{locale}` | 탐색 홈·외관 도감 | 기본값은 중국 출시·글로벌 미발표 외관; 전체 상태로 변경 가능 |
| `/{locale}/cosmetics/{id}` | 외관 상세 | 갤러리, 서버별 사실, 일정 근거, 관심 저장 |
| `/{locale}/calendar` | 로드맵 | 월간/목록 전환, 공식/예상 구분, 일정 미정 목록 |
| `/{locale}/watchlist` | 관심 외관 | 이 기기에 저장한 항목과 현재 상태 확인 |
| `/{locale}/updates` | 변경 소식 | 새 외관, 공식 발표, 예상 변경·철회, 정정 이력 |
| `/{locale}/about` | 안내 | 정보 확인 방법, 예상 기준, 출처·미디어 정책, 제보 경로 |

필터와 정렬은 URL에 저장해 공유·뒤로 가기가 가능합니다. 상세 페이지의 안정적인 ID는 번역명 변경과 무관합니다. 글로벌 출시를 확인하지 못한 자료를 곧바로 ‘미발표’로 분류하지 않습니다.

## 4. 주요 화면

### 탐색 홈

큰 홍보 문구 대신 검색과 실제 외관 카드로 시작합니다. 데스크톱은 넓이에 따라 3~4열, 모바일은 1~2열로 배치합니다.

```text
연운경 燕雲鏡   도감  로드맵  관심 외관  변경 소식        한국어 | EN
외관 검색 [ 이름 / 원명 / 별칭                         ]
[종류] [획득 방식] [글로벌 상태] [정렬]       총 N개
┌ 대표 이미지 ┐ ┌ 대표 이미지 ┐ ┌ 대표 이미지 ┐
│ 이름        │ │ 이름        │ │ 이름        │
│ CN 출시     │ │ 글로벌 확정 │ │ 예상·기간   │
│ 획득 방식 ♡ │ │ 날짜     ♡  │ │ 근거 수준 ♡ │
└─────────────┘ └─────────────┘ └─────────────┘
```

카드의 핵심 정보는 현지화 이름, 원명 확인 수단, 종류, 글로벌 상태, 일정이 있는 경우 그 정밀도, 관심 저장입니다. 전체 카드에 과도한 배지나 긴 설명을 채우지 않습니다. 예시 도형에는 실제 외관·일정을 넣지 않았습니다.

### 외관 상세

- 첫 영역: 대표 사진/갤러리와 이름·서버 상태·관심 저장.
- 미디어: 사진 확대, 앞·뒤·디테일, 체형별 변형, 영상 재생. 제공되지 않은 모습은 ‘자료 없음’으로 표시.
- 구성: 의상·헤어·장신구를 별도 항목으로 연결하고 세트 포함 여부 명시.
- 비교 정보: 중국 서버와 글로벌 서버의 출시일, 획득 방식, 가격/재화, 판매 기간을 별도 열로 표시. 모바일은 세로 배치.
- 일정: 공식 발표 또는 예상 범위, 근거 수준, 판단 근거, 확인일, 변경 이력.
- 하단: 출처·촬영 서버/버전·제공자·오류 제보.

중국 서버 영상은 플레이어 위에도 `CN 서버 영상 / CN footage`를 표시합니다. 염색·개조·홍보용 영상은 해당 조건을 표시합니다. 영상은 눌렀을 때 로드하고 자동 재생하지 않습니다. 외부 재생이 막히면 원문 링크로 안내합니다.

### 로드맵 캘린더

- 데스크톱 기본은 월간, 모바일 기본은 목록입니다. 두 보기 모두 동일한 기록을 사용합니다.
- 공식 날짜는 실선, 예상 범위는 점선·패턴과 텍스트로 구별합니다. 색에만 의존하지 않습니다.
- 월 단위 예상은 그 달의 별도 예상 영역에, 버전 단위 예상은 버전 그룹에 표시합니다. 임의의 하루로 바꾸지 않습니다.
- 날짜를 추정할 근거가 없는 외관은 ‘일정 미정’에 표시합니다.
- 첫 출시, 복각, 판매 종료를 구분하고 중국 서버 과거 일정은 별도 필터로 제공합니다.
- 사용자 선택 시간대와 공지의 원래 시간대를 함께 확인할 수 있습니다. 언어 선택이 서버나 시간대를 자동으로 바꾸지 않습니다.
- 지난 예상이 미확정 상태로 만료되면 ‘예상 기간 지남·재검토 중’으로 표시합니다. 자동 출시 처리나 다음 달 이월은 하지 않습니다.

### 관심 외관과 변경 소식

관심 목록은 이 기기의 저장소를 사용하며 회원 가입이 필요 없습니다. 저장 기능이 차단된 환경은 안내하고 나머지 탐색 기능은 유지합니다. 초기에는 실시간·메일 알림을 약속하지 않습니다. 변경 소식은 사이트 내 기록이며 개인별 ‘읽음’ 추적은 후속 기능입니다.

## 5. 사실과 예상의 표시

| 표시 | 의미 |
| --- | --- |
| 중국 출시 / Released in CN | 중국 출시 근거가 있는 사실 |
| 글로벌 미발표 / Not announced for Global | 확인일 기준 검토한 글로벌 공식 출처에서 대응 발표를 확인하지 못함 |
| 글로벌 출시 확정 / Confirmed for Global | 글로벌 공식 발표가 있음; 날짜 미정일 수도 있음 |
| 글로벌 출시됨 / Released in Global | 글로벌 출시를 확인한 기록이 있음; 현재 판매 중이라는 뜻은 아님 |
| 예상 / Estimated | 운영자의 판단이며 공식 사실과 별도 정보 |
| 일정 미정 / Unscheduled | 날짜 범위를 제시할 근거가 부족함 |

‘출시 여부’, ‘현재 획득 가능 여부’, ‘예상 존재 여부’는 서로 다른 값입니다. 예를 들어 글로벌 출시 이력이 있어도 현재 판매가 끝났을 수 있습니다. 예상의 근거 수준은 ‘근거 충분 / Supported’, ‘근거 제한적 / Limited’로 표현하고 통계적 확률처럼 보이는 백분율은 사용하지 않습니다. 자세한 규칙은 [콘텐츠 모델](content-model.md)에 정의합니다.

## 6. 언어와 이름

- 영어 화면은 `Winds Ahead`, 한국어 화면은 `연운경`을 대표명으로 사용합니다. 소개·푸터에서 `燕雲鏡`과 다른 언어명을 함께 표기합니다.
- UI 번역과 콘텐츠 번역을 분리하되 한 번의 콘텐츠 수정에서 두 언어를 함께 관리합니다.
- 이름은 중국어 원명, 검증된 글로벌 영어/한국어 공식명, 편집 번역, 검색 별칭을 구분합니다.
- 공식명이 없으면 ‘임시 번역 / Provisional translation’을 표시합니다. 번역 자체가 없으면 중국어 원명과 해당 언어의 ‘번역 준비 중’ 안내를 제공합니다.
- 서버 상태·날짜·가격 등 사실 값은 공통 데이터를 사용해 언어마다 달라지지 않게 합니다.
- 언어 전환 시 같은 외관·월·필터를 유지합니다. 중국어는 원문 데이터이며 세 번째 UI 언어가 아닙니다.

## 7. 시각 방향

**먹빛 배경 위에 실제 외관 사진이 돋보이는 현대적인 무협 도감**을 제안합니다. 제안 팔레트는 짙은 남청 `#101820`, 밝은 본문 `#F1F5F9`, 청옥색 강조 `#67D8C5`, 예상 표시용 호박색 `#F5BE63`입니다. 작은 제목·구획에만 거울의 원형 모티프와 세리프를 사용하고, 일반 UI는 읽기 쉬운 산세리프로 구성합니다.

실제 외관 이미지를 제품의 시각 중심으로 삼고 AI 이미지로 게임 외관을 대신하지 않습니다. 본문 16px 이상, 자주 쓰는 라벨 14px 이상, 충분한 대비, 키보드 조작, 사진 확대의 포커스 복귀, 움직임 줄이기를 지원합니다. 한글 자간을 억지로 벌리거나 모바일에서 캘린더를 가로 스크롤하도록 강요하지 않습니다.

## 8. 성공 기준과 다음 단계

초기 사용성 확인은 ‘이름 찾기 → 영상 보기 → 확정/예상 구별 → 관심 저장’이 설명 없이 가능한지로 판단합니다. 정보 품질 목표는 공개 기록의 출처·확인일 100%, 예상 기록의 근거·수정 이력 100%, 한국어/영어 핵심 화면 누락 0개입니다.

다음 단계는 대표 외관 자료 검증과 탐색 홈·상세·캘린더 와이어프레임입니다. 구현·배포는 이번 기획 산출물에 포함되지 않습니다. 단계별 완료 기준은 [개발 계획](delivery-plan.md), 조사 근거는 [출처 목록](../research-sources.md)을 참고합니다.
