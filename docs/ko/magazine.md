# 연운경 매거진

[English](../en/magazine.md) · [매거진](https://windsahead.com/ko/magazine)

사용자는 2026년 10월 1일 매거진을 도감·로드맵과 연결되는 핵심 기능으로 선택했습니다. 의미 있는 외관 업데이트와 로드맵 설명을 영어·한국어 회차로 편집하고, 독자가 다음 소재를 제안하게 합니다. 자료가 준비되면 발행하며 별도 정기 예약·계정 시스템·커뮤니티 자동 게시를 추가하지 않습니다.

## 읽기와 공유

주 메뉴는 외관·로드맵·매거진입니다. `/en/magazine`과 `/ko/magazine`에 발행한 회차를 모읍니다. `/ko/magazine/issue-01` 같은 안정적인 회차 주소에서 언어 전환·양언어 메타데이터·사이트맵을 지원합니다. 웹 기사에는 선택 가능한 본문·목차·참고사진·도감 및 로드맵 링크가 있으며 페이지 넘기기 뷰어를 요구하지 않습니다.

수정판 2는 언어별로 번호가 있는 사진 중심 JPG 여덟 장입니다. 여성 외관 사진이 꽉 찬 표지, 명조 제목, 크림·짙은 남색·세이지 지면, 얇은 구분선, 디테일 확대와 정면·후면 사진으로 패션 화보의 흐름을 만듭니다. 공식 출시 예고 네 가지에 각각 화보를 배정하며 연대학은 별도의 예상 후보 지면에 담습니다. 가로 1080px, 세로는 내용에 따라 달라지며 기사 아래에서 개별 이미지와 ZIP 묶음을 받습니다. 모바일 표시 너비에서 가독성을 확인합니다. 실제 게시 플랫폼의 압축·업로드 규칙은 검증하지 않았습니다. 공유 시 회차·출처·예상 표시를 유지합니다.

창간호 **다음 옷장을 미리 펼치다**는 창간의 말·홍염의 밤·글로벌 10월 4일 공식 외관 네 가지·기존의 제한적 예상 사례·할인 종료와 판매 종료의 차이·독자 참여 안내를 담습니다. 정보 기준일은 2026년 10월 1일이며 발행일 시간대는 America/New_York입니다. 실제 게임 내 판매 확인을 주장하지 않습니다.

## 편집 기록과 미디어

`site/content/magazine.json`에서 양언어 원고·회차 ID·발행일·정보 기준일·출처 ID·정정·고정된 예상 수정 번호를 관리합니다. 발행된 회차는 당시의 기록입니다. 오늘의 예상으로 조용히 덮어쓰지 않고 과거 판단을 보존하며 정정과 수정판 번호를 추가합니다. 도감·로드맵에서 최신 정보를 제공합니다. 여러 GitHub 릴리스를 한 호에 묶을 수 있으며 소프트웨어 버전과 매거진 회차는 별개입니다.

웹판과 공유판에 기존의 출처가 연결된 중국 공식 참고사진을 사용합니다. 홍염의 밤·연대학은 확인된 여성 모습을 우선하며 전체 원본은 도감에서 볼 수 있습니다. 글로벌 실착을 확인한 사진이 아닙니다. 사용자가 요청한 사진판의 원본 경로·URL·미확인 허가 상태를 `site/content/magazine-export-metrics.json`에 기록합니다. 사진 권리는 원저작자에게 있으며 출처 표기가 재배포 허가를 뜻하지 않습니다. 게임 이미지는 코드 라이선스에서 제외됩니다. 최초의 타이포그래피판은 원래 파일 경로에 과거 기록으로 보존합니다.

독자 제안은 공유 게시글의 댓글이나 기존 공개 GitHub 이슈 경로로 받습니다. GitHub에는 계정이 필요합니다. 제안은 편집 소재 선정에 참고하며 순위·게재를 보장하지 않습니다. 독자 이름·사진을 게재하기 전에 동의와 사용 범위를 확인합니다.

## 제작 절차

1. 검증된 소재와 출처를 선정하고 중국 사실·글로벌 사실·예상을 구분합니다.
2. 두 언어 원고를 함께 검토하고 미정 값·날짜 정밀도·시간대를 유지합니다.
3. `site/scripts/render-magazine.mjs`로 공유 이미지를 만듭니다. Playwright와 설치된 Chrome이 필요하며 기존 실행 환경의 모듈 경로를 `WINDS_BROWSER_MODULES`로 지정할 수 있습니다. 사이트의 의존성은 추가하지 않습니다.
4. 언어별 JPG 여덟 장으로 ZIP을 만듭니다. 새 글자가 필요하면 기존 라이선스 글꼴 서브셋을 다시 만들고 OFL 고지를 유지합니다.
5. 콘텐츠 검증(출처 ID·예상 이력·JPG·WebP 크기/용량·사진 출처·ZIP 존재 포함), 타입·테스트·배포 빌드를 실행합니다. 모바일·데스크톱 읽기·이동·언어 전환·다운로드를 확인합니다.
6. [릴리스](releasing.md)와 기존 Sites 게시 절차를 따릅니다. 커뮤니티 게시는 별도로 명시적인 요청을 받아 수행합니다.

수정판 2의 브라우저 검증과 제한은 [v0.3.1](releases/0.3.1.md)에 기록합니다. 웹사이트는 고해상도 파일 대신 작은 WebP 미리보기를 지연 로드하며 이미지 공간을 미리 확보합니다. 실제 기기·커뮤니티 업로드·새 분석 도구의 검증 결과를 주장하지 않습니다.
