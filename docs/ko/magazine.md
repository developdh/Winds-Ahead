# 연운경 매거진

[English](../en/magazine.md) · [매거진](https://windsahead.com/ko/magazine)

매거진은 검증된 외관 예고와 획득 정보를 영어·한국어 사진 회차로 정리합니다. 별도 정기 예약이나 커뮤니티 자동 게시를 추가하지 않으며 현재 기사와 공유판에는 [공식 일정 정책](official-schedules.md)을 적용합니다.

창간호 ‘10월 외관 업데이트’는 2026년 10월 1일 정보 기준일과 America/New_York 발행 시간대를 유지합니다. 수정판 5는 연대학 예상과 표지 언급을 제거합니다. 언어별 1080px JPG 6장은 표지·공식 10월 4일 예고 외관 네 가지·사이트 소개로 구성합니다. 웹 기사에는 불꽃 축제의 밤 할인 종료 해석도 유지하며 실제 글로벌 판매는 미확인입니다.

`site/content/magazine.json`에 양언어 기사·출처·정정 이력을 기록합니다. 다운로드가 달라지면 수정판 번호를 갱신합니다. 이전 공유판은 Git 이력에 보존하고 공개 자산에서는 제거합니다. 기존 출처가 명시된 중국 공식 참고사진을 사용하며 재배포 권한은 미확인입니다. 사진은 코드 라이선스에서 제외하고 전체 원본은 도감에 유지합니다.

설치된 Chrome/Playwright와 선택적 `WINDS_BROWSER_MODULES`를 사용해 `site/scripts/render-magazine.mjs`로 생성하고 언어별 JPG 6장을 ZIP으로 묶습니다. 사진 출처·크기·용량·미리보기 공간 확보와 한영 모바일 읽기·다운로드를 확인한 뒤 [릴리스 절차](releasing.md)를 따릅니다. 폰트 라이선스를 유지하고 커뮤니티 게시는 별도 사용자 승인을 받습니다.
