# 소스 공개 준비 · 2026년 9월 13일

[English](../en/public-launch.md) · [README](../../README.ko.md)

연운경은 수익을 창출하지 않는 독립 팬 프로젝트입니다. 누구나 코드, 번역, 접근성, 출처가 있는 정보와 오류 수정으로 참여할 수 있습니다. 광고, 유료 기능, 제휴 수익 및 수익 수취를 운영하지 않습니다.

## 공개 범위

- 외관 기록 684개, 위키 참고 항목 395개, 외관 368종에 정지 참고 사진 491장입니다. 316개 기록은 검토된 사진이 아직 없습니다. 게임 전체를 빠짐없이 수록했다는 뜻은 아닙니다.
- 중국 공식 사진 36장을 의상 19종에 추가했습니다. 그중 12종은 첫 사진입니다. 새 썸네일 총 1,745,780바이트, 확대용 이미지 총 9,886,806바이트이며 원본 파일은 제공하지 않습니다. [출처 검토 기록](../research/2026-09-13-photo-expansion.json)
- 사진별 대체 텍스트와 필요한 원화·염색 예시 표시를 추가했습니다. 중국 사진으로 글로벌 출시를 확정하지 않습니다.
- 화면 내 상세 팝업·갤러리, 획득 정보, 서버별 출시 상태, 확정·예상 로드맵, 캘린더, 관심 저장 및 공유를 제공합니다.
- 공개 기여 안내, 정보 수정·삭제 요청 양식, 보안 제보 안내, 행동 강령, 자체 코드용 MIT 라이선스를 갖췄습니다. 게임 미디어·위키 편집물 등 제삼자 자료의 권리는 별도로 유지합니다. [권리 고지](../../THIRD_PARTY_NOTICES.md)

## 공개 전 보완

React, React Server Components, vinext, Vite와 Cloudflare 도구를 호환되는 보안 수정 버전으로 갱신했습니다. 팝업을 여는 링크가 별도 상세페이지까지 미리 내려받지 않도록 했습니다. 언어별 대표·대체 주소, 사이트맵, 검색 로봇 규칙, 한국어·영어 오류 복구 화면을 추가했습니다. 개인 관심 목록은 검색 색인에서 제외합니다.

관련 원문은 [React Server Components](https://github.com/advisories/GHSA-wx67-qw84-cm4g), [Vite](https://github.com/advisories/GHSA-fx2h-pf6j-xcff), [image-size](https://github.com/advisories/GHSA-w3rx-r6r6-pgpr) 보안 공지를 참고하세요. 의존성 갱신과 검사 통과가 모든 취약점의 부재를 보장하지는 않습니다.

## 검증과 남은 범위

실행 환경 갱신 후 타입 검사, 기존 도메인·미디어 회귀 테스트 32개, 콘텐츠 검증을 통과했습니다. 최종 검증 결과는 공개 준비 PR에 기록합니다. 이번 운영 의존성 검사에서 알려진 취약점은 0건입니다. 개발 전용 Drizzle Kit 도구에는 보통 위험 4건이 남아 있으며 해당 개발 서버를 서비스에서 노출하지 않습니다. 제안되는 비호환 버전 강제 다운그레이드는 하지 않습니다.

Gitleaks로 커밋 45개를 포함한 전체 이력을 확인했고 인증 정보 패턴이 발견되지 않았습니다. 공개 DNS 검증값과 비밀이 아닌 Sites 프로젝트 식별자는 의도적으로 남깁니다. API 키와 로컬 환경 파일을 공개하면 안 됩니다.

브라우저 점검만으로 실제 iOS·Android 기기나 실제 방문자의 웹 성능을 검증했다고 보지 않습니다. 첫 로딩 자바스크립트 목표 용량은 여전히 보완할 항목이며 이펙트 영상과 확대 갤러리는 필요할 때 불러옵니다. 날짜를 모르는 출시는 미정으로, 예상은 운영자 판단으로 구분합니다.


최종 로컬 타입 검사, 테스트 32개, 콘텐츠·미디어 검증, Worker 빌드를 통과했습니다. 배포용 결과에서 한국어·영어 팝업 링크의 대표 주소가 개별 상세 주소로 연결되고, robots.txt는 200, 사이트맵은 주소 1,376개, 없는 경로는 404를 반환했습니다. 320·360·390·768·1024·1440 CSS px에서 팝업이 화면 안에 들어왔습니다. 추가 사진의 실제 로딩과 언어 변경 시 검색어 유지도 확인했습니다. Chromium 기준이며 실물 기기나 저속 네트워크 검증을 했다고 주장하지 않습니다.

전체 클라이언트 청크 16개의 gzip 합계는 422,217바이트로 이전 418,797바이트보다 3,420바이트 늘었습니다. 나중에 불러오는 청크까지 포함한 값이며 첫 페이지 전송량은 아닙니다. 이 검사로 최초 자바스크립트 200KB 목표 달성을 확인한 것은 아닙니다.


## 공개 상태

저장소 공개 여부와 웹사이트 접근 권한은 별개입니다. GitHub 소스를 공개할 준비를 진행 중이며 연결된 사이트는 현재 소유자 전용입니다. 업데이트 배포는 이 접근 범위를 유지합니다. 누구나 접속할 수 있는 웹사이트 공개는 명시적인 접근 범위 변경이 필요합니다. 홍보 글은 초안이며 사이트가 소유자 전용인 동안 게시하면 안 됩니다.

도메인 연결 당시 두 호스트의 연결 및 TLS 활성 상태를 확인했습니다. 대표 주소는 `https://windsahead.com`이며 `www` 리디렉션이나 비로그인 접근을 설정했다는 뜻은 아닙니다. [도메인 연결 이력](custom-domain.md)
