# 사이트 현황과 콘텐츠 운영

[English](../en/mvp-status.md) · [README](../../README.ko.md) · [최신 릴리스](releasing.md)

2026년 9월 29일 갱신. [연운경](https://windsahead.com/ko)과 소스 저장소는 공개 상태입니다. 초기 소유자 전용 MVP는 [9월 13일 공개 전환](public-launch.md) 이후의 운영 상태로 대체됐으며, 당시 수량·검증 기록은 날짜별 문서에 보존합니다.

## 구현된 이용 흐름

- 영어·한국어 입장 화면, 언어 기억·직접 링크 복원, 어두운 사진 중심 외관 도감, 분류·획득처 필터, 검색·기기 내 관심 목록.
- 서버별 공식 명칭·획득 조건·출처 이력, 전체 이미지 갤러리, 여성 우선 참고 사진, 키보드·스와이프 이동과 클릭 후 로드되는 이펙트 영상.
- 서버별 공식 캘린더·로드맵, 운영자 예상과 재검토 알림·수정 이력, 판매·교환·할인·이벤트 종료 일정.
- 필요한 때 로드하는 커뮤니티 위키 구성품·외형 정보. 커뮤니티 사진으로 공식 출시 상태·중국 항목 대응·재배포 허가를 확정하지 않습니다.

## 현재 콘텐츠 수량

외관 716개, 외관 457개에 정지 이미지 667개가 연결돼 있으며 259개는 확인된 사진이 없습니다. 서버별 기록 639개, 글로벌 캘린더 일정 211개, 구조화한 종료 일정 24개, 보존된 예상 수정 16개, 위키 연결 395개(본문 있는 문서 383개)를 포함합니다. 저장소 기준 수량이며 게임 전체 외관을 빠짐없이 담았다는 의미가 아닙니다. 대응 미확인 항목은 서버별로 남을 수 있습니다.

## 기준 파일

아래 경로는 모두 `site/` 아래입니다.

| 파일 | 역할 |
| --- | --- |
| `content/research.json` | 외관 식별·중국 원명·근거·사진·영상 |
| `content/localizations.json` | 영어·한국어 설명과 대체 한국어 명칭 |
| `content/media.json` | 최적화된 미리보기·전체 이미지·용량·권리 상태 |
| `content/regional-records.json` | 중국·글로벌 상태·대응 근거·획득 조건 |
| `content/global-events.json` | 공식 글로벌 출처와 날짜가 있는 일정 |
| `content/deadlines.json` | 서버·정밀도를 보존한 획득·할인 종료 |
| `content/forecasts.json` | 운영자 예상 수정 이력·근거·재검토일 |
| `content/updates.json` | 영어·한국어 갱신 기록 |
| `public/data/wiki/` | 출처를 표시하는 지연 로드 커뮤니티 상세 |
| `scripts/validate-content.mjs` | 콘텐츠·번역·서버·파일 검증 |
| `scripts/validate-history.mjs` | 이전 예상 수정·삭제 방지 |

## 점검과 발행

[캘린더 유지보수](calendar-automation.md)에 따라 공식 중국·영어·한국어 공지를 읽고 명칭·획득처·종료일·빈 갤러리를 함께 확인합니다. 미확인 정보와 접근 실패를 명시하고 항목·예상 수정·PR·예약의 중복을 피합니다. 공개된 이미지의 출처 표기는 포괄적인 재배포 허가가 아닙니다.

리뷰 가능한 브랜치와 영어 PR에 영어·한국어 문서를 함께 반영합니다. 타입·테스트·콘텐츠·이력 검증과 프로덕션 빌드를 실행하고 영향을 받는 영어·한국어 모바일·데스크톱 흐름을 확인합니다. 완료된 업데이트마다 [릴리스 절차](releasing.md)에 따라 버전·CI를 검증하고 발행합니다. GitHub 릴리스와 Sites 배포는 별도 결과이며 자동 병합은 비활성 상태를 유지합니다.

## 검증 한계

현재 검증은 [v0.2.12 기록](releases/0.2.12.md)을 기준으로 하며 이전 테스트 수량은 과거 기록입니다. 실제 iOS·Android, Firefox·WebKit, 200% 텍스트 확대, 느린 네트워크·실사용 Core Web Vitals는 별도 검증이 필요합니다. 초기 JavaScript 200 KB 목표도 아직 입증되지 않았습니다. 공개 이슈에서 정정·삭제 요청을 받으며, 제3자 이미지는 코드 라이선스에 포함되지 않고 재배포 허가는 미확인입니다.

## 매거진 · 2026년 10월 1일

양언어 매거진 목록·창간호·언어별 모바일 PNG 여섯 장·ZIP 다운로드를 추가했습니다. 주 메뉴는 외관·로드맵·매거진입니다. 회차 직접 링크는 최초 언어 선택 화면을 거치지 않고 해당 언어로 읽습니다. 검증과 미디어 제한은 [제작 정책](magazine.md) 및 [v0.3.0](releases/0.3.0.md)에 기록합니다.

수정판 2는 현재 다운로드를 언어별 사진 화보 여덟 장으로 교체하며 소개한 출시 예고 외관과 예상 후보를 모두 사진으로 담습니다. 작은 WebP 미리보기로 기사 로딩 용량을 줄입니다. [v0.3.1](releases/0.3.1.md)에 기록합니다.

수정판 3은 감상·편집 문구와 참여 유도를 제거하고 모바일 사진판을 구조화된 정보 여섯 장으로 줄입니다. 웹 기사에도 같은 중립적 문체를 적용합니다. [v0.3.2](releases/0.3.2.md)에 기록합니다.

수정판 4는 기존 정보 여섯 장 뒤에 짧은 연운경 소개 면을 7번째로 추가합니다. 이전 수정판을 보존합니다. [v0.3.3](releases/0.3.3.md)에 기록합니다.
