# MVP 현황과 콘텐츠 운영

[English](../en/mvp-status.md) · [README](../../README.ko.md)

2026년 9월 13일 UTC 갱신. 구현한 소유자 비공개 MVP의 현황이며 공개 서비스 준비가 완료되었다는 뜻은 아닙니다.

## 구현 범위

- 첫 접속: 하나의 이미지와 명조 제목, 세로 언어 선택 두 개, 짧은 로딩 전환으로 구성한 랜딩입니다. 재방문 시 언어를 다시 묻지 않습니다. 상세·캘린더 링크는 선택 후 원래 경로와 검색 조건으로 이어집니다. 저장소를 사용할 수 없어도 일회성 진입 표시와 메모리 설정으로 재선택 반복 없이 탐색합니다.
- 주요 동선은 외관과 캘린더입니다. 검색·종류 선택을 한 도구 모음에 두고 작은 책갈피로 관심 모음을 엽니다. 사용자의 단순화 요청에 따라 추가 정렬, 캘린더 필터, 보기 방식 조작을 줄였습니다.
- 상세에서 이미지, 글로벌 상태, 중국 날짜·획득 정보를 바로 읽고 출처 기록을 펼칩니다. 전체 이미지는 요청할 때 불러옵니다. 외관별 영상은 검증된 YouTube 재생, Bilibili 링크, 최적화한 NetEase 공식 영상을 지원합니다. 이펙트는 클릭 후 재생하고 화면 밖으로 나가거나 숨겨지면 재생기를 제거합니다. 소개의 트레일러는 일반 게임 소개용입니다.
- 캘린더는 중국 기록과 별도 검증한 글로벌 일정을 구분하며 데스크톱 월간·모바일 목록, 월 이동, 미정 외관을 제공합니다. 예상은 월·기간·버전 정밀도와 이전 판단·변경 이유를 보존합니다.
- 접근 가능한 이름, 키보드 조작·갤러리, 초점 표시, 동작 줄이기, 최적화 이미지와 폰트를 적용합니다. 지원 환경의 WebMCP 도구도 UI와 같은 검색·관심 저장 로직을 사용합니다.

## 원본 콘텐츠 위치

아래 경로는 모두 `site/` 기준입니다.

| 파일 | 역할 |
| --- | --- |
| `content/research.json` | 검증한 중국 출처 스냅샷, 원명·날짜·획득 정보·이미지 출처·외관 영상 |
| `content/localizations.json` | 외관 ID별 임시 한국어 독음과 영어·한국어 설명 |
| `content/media.json` | 비공개 최적화 이미지 경로·원본 주소·용량·소유자·미확인 재사용 권한 |
| `content/global-events.json` | 글로벌 출처와 명시적 일정. 중국 날짜에서 자동 복사하지 않음 |
| `content/forecasts.json` | 양언어 판단·가정·근거·재검토일을 가진 추가형 예상 변경 기록 |
| `content/updates.json` | 출처 ID를 연결한 양언어 게시·변경 로그 |
| `scripts/validate-content.mjs` | 형식·참조·날짜 정밀도·번역·영상 제공자·미디어 검사 |
| `scripts/validate-history.mjs` | Git 기준점의 이전 예상 수정·삭제 방지 |

비공개 이미지·영상 파생본은 `media.json`과 `research.json`에 기록했습니다. 현재 권한 스냅샷은 해당 복제본을 반영하며 공개 재배포 권한은 미확인입니다.

## 갱신 절차

1. 공식 자료를 직접 확인하고 서버·범위·게시일·출시일·근거·미정 값을 기록합니다.
2. 안정적인 외관 ID와 양언어를 함께 추가합니다. 출처 없이 임시 이름을 공식 이름으로 승격하지 않습니다.
3. 정확히 같은 외관의 미디어를 연결하고 이용 근거를 기록합니다. 허용된 이미지를 최적화하며 영상 ID·제공자 주소·출처가 서로 맞아야 합니다.
4. 글로벌 사실을 별도로 등록합니다. 예상 판단이 바뀌면 새 변경 기록을 추가하며 과거 기록을 고쳐 정확했던 것처럼 보이게 하지 않습니다.
5. README의 네 검증을 실행하고 영향받은 모바일·데스크톱 화면을 확인합니다. 예상이 바뀌면 대상 Git 기준점으로 이력 검사를 실행합니다.
6. 양언어 로그를 갱신하고 영어 콘텐츠 PR을 만들거나 수정합니다. 초기 정기 점검은 별도 GPT API 없이 이 작업에서 수행합니다. 정기 제안을 자동 병합·배포하지 않습니다.

## 검증과 제한

- 날짜·정밀도·달력 경계·서버 근거 분리·변경 기록·손상된 관심 목록·번역 누락·획득 비용·영상 주소·정지 이미지·영상 용량 검사 18개가 통과했습니다. 외관 18종, 이미지 22개, 번역 18개, 업데이트 3개의 콘텐츠 검사가 통과했습니다.
- 브라우저에서 첫 언어 선택, 양언어 재방문 기억, 언어 변경, 상세 링크·검색 조건 보존, 검색, 관심 저장, 이미지 확대, 중국 일정 기록을 확인했습니다. 인앱 브라우저에서 320–1440 CSS px 반응형을 확인했으며 실제 기기 인증은 아닙니다.
- 게시용 빌드에서도 언어 전환·검색 조건을 유지한 상세 이동·이미지 확대·캘린더 이동을 확인했습니다. 지연 로드하는 링크에서 필요한 이동 함수가 빌드 중 누락되는 문제를 막도록 클라이언트 진입점의 내보내기를 보존했으며, 수정 후 해당 동선에서 새 사전 로드 오류가 발생하지 않았습니다.
- 현재 썸네일 22개의 합계는 1.57MB이며 첫 3개 이후는 지연 로드합니다. 전체 이미지는 요청할 때 불러옵니다. 초기 8종의 합계는 약 542KB였습니다. 첫 이펙트 영상은 4.18MB로 클릭 후에만 불러옵니다. 폰트는 라이선스를 유지한 로컬 서브셋입니다. 빌드 용량은 실제 사용자 Core Web Vitals가 아니며 p75 LCP/INP/CLS·느린 기기와 통신 환경 목표는 미측정입니다.
- 실제 iOS·Android, Firefox·WebKit, 텍스트 200% 확대 검증은 별도로 남았습니다. 공개 제보 채널·미디어 재배포 허가·예측 정확도 주장은 포함하지 않습니다.
- GitHub에는 검토 가능한 단계별 PR을 남겼습니다. main 병합과 자동 병합은 수행하지 않았습니다.
