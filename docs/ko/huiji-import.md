## 반영 범위 · 2026-09-13

커뮤니티 자료의 외관 **139개**를 추가하여 도감이 **684개 기록**으로 확장되었습니다. 위키 참고 항목 **395개**는 세트 219개, 무기 125개, 무학 이펙트 30개, 탈것 21개입니다. 실제 본문 **383개**, 미작성 빨간 링크 **12개**를 구분합니다. 별도 단품 메뉴는 헤어 선택 후에도 빈 표였습니다. 게임 전체 목록의 완전성을 뜻하지 않습니다.

세트의 **898개 구성 행**에 부위별 영어·한국어 명칭, 가능한 구성품 원문 링크, 등급, 염색·재단·선물·거래 여부, 풍화치, 수집 보상과 결산 연출을 제공합니다. 무기 종류, 적용 무학, 변경 초식, 탈것 종류, 위키 획득처와 시기도 실제 기재된 경우에 표시합니다. 값이 없는 템플릿 행은 제외합니다. 공식 번역이 없는 고유명은 한국어에서 중국 원명을, 영어에서 편의 독음을 사용합니다.

## 출처와 동일 외관 판단

- **燕云十六声中文维基 기여자**를 표시하고 **CC BY-NC-SA 3.0**으로 재구성하며 원문과 확인한 수정 이력을 연결합니다. 위키 이미지 파일은 복제하지 않았습니다. 해당 이용 조건은 위키 기반 자료에 적용되며 NetEase 이미지나 프로젝트 전체의 권한을 뜻하지 않습니다.
- 위키만 있는 새 기록은 공식 출시일·글로벌 명칭·검증 가격을 미확인으로 유지합니다. 위키 일정을 캘린더로 자동 전환하지 않으며 원문 시기와 미확인 시간대를 보존합니다.
- 시리즈 접두어가 붙은 무기 10개는 원명과 종류를 대조해 기존 공식 기록에 연결했습니다. 부신 콜라보는 중국 공지에 기재되어 있습니다. 판단 기록은 `docs/research/huiji/identity-map.json`에 남겼습니다. 이름이 같은 **霜寒天泉 세트와 헤어**는 별도 분류입니다.
- **풍화치는 수집 점수이며 가격이 아닙니다.** 세트 완성 장명옥 100개는 받는 보상입니다. 공란을 불가로 바꾸거나 구성품 합계를 세트 점수에 임의로 맞추지 않습니다.
- 공식 공지로 무기 6개의 비용을 과거 한정 가격 **음옥 2개**로 바로잡았습니다. 5개는 무료 공유 보상을 무기와 혼동했고 1개는 미확인이었습니다. 수정 전후와 원문 주소는 `acquisition-corrections.json`에 보존합니다. 공식 출시일은 바꾸지 않았습니다.

## 운영과 검증

`site/scripts/import-huiji.py`는 저장한 원문을 변환하며 네트워크 요청을 하지 않습니다. ICU `uconv`로 편의 독음을 만들고 검토된 이름 연결과 분류 검사로 중복·동명 혼동을 방지합니다. `site/public/data/wiki/`에 항목별 작은 JSON 문서를 생성합니다. 상세 기능과 현재 항목만 필요할 때 불러와 도감에서 위키 전체 자료를 다운로드하지 않습니다. 기존 이미지와 클릭 후 재생 영상은 유지합니다.

타입 검사, 콘텐츠 검증과 **테스트 24개를 통과**했습니다. 출처·문서 ID·분류·미기재 여부·미작성 문서·가격과 보상 구분·공식 서버 근거를 검사합니다. **320·360·390·768·1024·1440px**에서 가로 넘침이 없고 구성품 링크의 44px 터치 영역을 확인했습니다. 인앱 Chromium에서 한국어 모바일 구성 화면과 영어 데스크톱 상세를 검토했습니다. 실제 휴대폰, Firefox, WebKit, 글자 200% 확대와 실사용 성능은 이번 변경에서 검사하지 않았습니다.

최종 빌드 측정은 아래에 기록합니다. 초기 JavaScript 200KB 목표 달성은 아직 별도 검증이 필요하며 위키 정보 지연 로딩만으로 사이트 전체의 성능 목표 달성을 주장하지 않습니다.
