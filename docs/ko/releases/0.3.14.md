# 0.3.14 — 10월 25일 글로벌 외관과 공식 명칭

[English](../../en/releases/0.3.14.md) · [웹사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-10-22.md) · [PR #55](https://github.com/developdh/Winds-Ahead/pull/55)

10월 25일 글로벌 외관 예고 10종에 한영 공식명·독립적으로 확인한 글로벌 가격·구조화한 판매 및 할인 종료 7건을 추가했습니다. 점등 대길의 랜덤 스타일 다섯 종과 별도 완성 보상 우산의 획득 방법을 구분합니다. 상자당 장명주 60개를 특정 스타일의 확정 가격으로 표시하지 않으며 별도 완성 보상 수령 마감을 추정하지 않습니다. 황금빛 도약의 11월 25일 마감은 판매 종료가 아닌 할인 종료입니다. 영문 시간대 표기·한국어의 시간대 없는 시각·한국어 이미지의 이전 머리말을 근거에 보존했습니다.

공식 명칭별 사진 대조로 기존 중국 항목 8종을 연결했습니다. 순풍백록·황금빛 도약은 중국 후보의 사진 대응 근거가 부족해 별도 글로벌 항목으로 유지합니다. 미발표 일정이나 다른 서버 가격을 추정하지 않습니다.

첫 원격 검증은 10월 22일 새로 검토된 Next.js 패키지 보안 공지 세 건으로 실패했습니다. [이미지 최적화](https://github.com/advisories/GHSA-2464-fhr4-w9xw)·[Server Actions 자원 고갈](https://github.com/advisories/GHSA-p3m5-59mp-jv5r)·[캐시 직렬화](https://github.com/advisories/GHSA-673q-mjm6-r5xr) 수정이 포함된 16.4.2로 Next.js와 대응 ESLint 설정을 16.3.8에서 올리고 잠금 파일을 갱신했습니다. 패키지 감사 항목을 해결한 것이며 이 Vinext 배포에서 실제 공격 가능성을 확인했다는 뜻은 아닙니다. 패치 뒤 프로덕션 감사와 필수 검증을 다시 실행했습니다.

여성 의상 우선 표시·우산 6종 집중 사진·전체 포스터·원본 GIF와 연결된 정지 프레임을 포함해 글로벌 참고 사진 12장을 추가했습니다. 근거가 부족했던 중국 과거 출시 확정 7건은 명시된 예정일을 보존하면서 출시 확인 중으로 바로잡았습니다. 최종 수량은 외관 741개·외관 495종의 사진 872장·빈 갤러리 246개·서버별 기록 691개·글로벌 일정 241개·종료 일정 66개입니다.

검증 통과: TypeScript·기존 테스트 44개·콘텐츠/사진/출처·예상 이력 보존·Sites 빌드 도우미와 저장소 루트 진입점의 프로덕션 Worker 빌드. 인앱 Chromium에서 10종 모두 한국어 390px·영어 1440px 상세를 확인했고 대표 사진·확대 갤러리 10곳·원본 링크·닫은 뒤 초점 복원이 정상입니다. 한국어 탈것 상세는 320/360/390/768/1024/1440px에서 가로 넘침이 없습니다. 한영 로드맵·캘린더에 10월 25일 경로 10건이 표시되고 언어 전환 시 캘린더 모드를 유지했습니다. [화면 검증 기록](../../research/2026-10-22-ui/results.json).

전체 콘텐츠 화면 점검은 의존성 패치 전에 수행했습니다. 16.4.2 적용 후 필수 로컬 검증과 프로덕션 감사를 다시 통과했으며 보고된 프로덕션 취약점은 0건입니다. 배포용 Worker 브라우저에서 한국어 탈것 상세·영어 상세 언어 전환·저장 언어에 따른 루트 이동·로드맵 클라이언트 이동·한영 캘린더 모드 보존을 재확인했습니다. 해당 확인에서 경고·오류 로그는 없었습니다. [의존성 검토](../../research/2026-10-22-dependency-review.json).

새 정적 WebP 파생 파일 48개의 합계는 전체 사진 2,071,274바이트·썸네일 505,560바이트·선택 미리보기 48,690바이트·집중 표시 사진 881,538바이트입니다. 이는 파일 합계이며 첫 화면 전송량 측정값은 아닙니다.

현재 게임 내 획득 여부·한국 공식 카페 본문·전체 소셜 이력·실물 기기·Firefox/WebKit·200% 텍스트 확대·느린 네트워크·실사용 Core Web Vitals는 미확인입니다. 기존 프레임워크·청크 경고가 남아 있습니다. 사진 재배포 허가는 미확인입니다. 이전 예상 이력·정기 예약·매거진 공유판·공개 사이트 접근 범위는 바꾸지 않았습니다.
