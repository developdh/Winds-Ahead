# 0.3.7 — 중국 10월 9일 외관과 복각 조건

[English](../../en/releases/0.3.7.md) · [웹사이트](https://windsahead.com/ko) · [출처 점검](../content-review-2026-10-12.md) · [PR #48](https://github.com/developdh/Winds-Ahead/pull/48)

풍풍호호·필회만상·취람산월에 중국 공식 10월 9일 예고, 획득 가격과 할인 종료 3개 일정을 등록했습니다. 호랑이 가격은 귀·손목 장식·자세 묶음 가격이며 사진 속 의상은 구성품이 아닙니다. 글로벌 공식명과 일정은 미정으로 유지합니다.

기존 鹊踏枝 항목에 중국 복각, 현재 유료 강호령 해제 후 68위안 직접 구매, 구성품·상자 조건과 12월 25일 04:59:59 판매 종료를 보완했습니다. 강호령 가격은 별도로 미표기이며 98위안은 향후 재복각 가격입니다. 최초 출시일은 미정이고 중복 등록하거나 날짜 경과만으로 출시 확인 처리하지 않았습니다. 모든 원문 시간대는 미확인입니다.

중국 공식 사진 9장을 추가했습니다. 묶음·의상은 여성 사진을 우선하고 달빛 이펙트는 인물 중심 미리보기와 전체 배너를 함께 유지했습니다. 도감은 외관 723개, 외관 473종의 사진 799장, 서버별 기록 652개, 글로벌 일정 216개, 종료 일정 33개입니다. 이미지 재배포 권한은 미확인이며 원본 URL과 위키 상세 참고를 유지합니다.

검증: 타입 검사, 도메인·미디어 테스트 44개, 콘텐츠 검사, 예상 이력 보존 검사와 배포용 Worker 빌드가 통과했습니다. 운영 의존성 감사에서 알려진 취약점은 0개였습니다. 앱 내 Chromium에서 한국어 상세 4개를 390px, 영어 상세 4개를 1440px로 확인하고 대표 사진, 서버별 미확인 상태, 가격과 초 단위 종료일을 점검했습니다. 확대 갤러리에서 달빛 이펙트 전체 배너가 로드됐고, 가장 긴 한국어 복각 상세 화면은 320/360/390/768/1024/1440px에서 가로 넘침이 없었습니다. 수집된 브라우저 경고·오류는 없었습니다. [화면 검증 기록](../../research/2026-10-12-ui/results.json). 새 썸네일 합계는 521,708바이트, 전체 사진 파생본은 1,950,776바이트, 작은 미리보기는 29,332바이트입니다. 첫 화면 전송량 측정값은 아닙니다.

한국 공식 카페 접근에 실패했고 공식 SNS·게임 내 판매 여부는 별도 확인하지 않았습니다. 실물 기기·Firefox/WebKit·200% 텍스트 확대·실사용 성능은 미검증이며 기존 프레임워크·청크 경고는 남아 있습니다. 예상 감사 이력·정기 점검·매거진 판본·사이트 공개 범위는 변경하지 않았습니다.
