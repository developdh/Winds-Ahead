# 0.3.13 — 중국 획득 조건·본편 보상 사진 보완

[English](../../en/releases/0.3.13.md) · [웹사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-10-19.md) · [PR #54](https://github.com/developdh/Winds-Ahead/pull/54)

천상의 별빛·별 쏟아지는 들녘·긴 꿈속의 별의 중국 과거 시즌 공명 획득처·재화를 보완했습니다. 2026년 6월 26일 04:59:59 종료 3건을 초 단위·시간대 미정으로 추가했습니다. 중국 회당 수량·확률·보장 횟수는 미정이며 글로벌 보상풀 규칙과 구분합니다. 근거가 부족한 중국 출시 확정 3건은 실제 출시 확인이 필요한 예고로 정정하고 기존 날짜는 보존했습니다.

본편 장신구 오현비파 / Wu Xian Pi Pa·지월량 / Zhi Yue Liang의 임무 보상·본편 시작 조건과 명칭이 적힌 공식 사진 2장을 보완했습니다. 미리보기는 여성 비파 착용 사진과 고리·술을 포함한 종이 달에 집중하며 확대에서는 전체 포스터·원본 링크를 유지합니다. 영어·한국어 이름은 임시 독음입니다. 개별 보상 임무·최초 출시일·글로벌 대응은 미정입니다. 총 외관 739개, 외관 493개의 사진 860장, 빈 갤러리 246개, 서버별 기록 681개, 글로벌 일정 231개, 종료 일정 59개입니다.

타입 검사·기존 테스트 44개·콘텐츠/미디어/출처 검증·예상 이력 불변 검사·저장소 루트 프로덕션 Worker 빌드를 통과했습니다. 프로덕션 의존성 감사에서 알려진 취약점은 0건입니다. 기존 프레임워크/설정·대형 청크 경고는 남아 있습니다.

인앱 Chromium에서 영향받는 상세 5종을 한국어 390px·영어 1440px로 확인했습니다. 새 전체 갤러리 2종과 원본 링크, 중국·글로벌의 별도 공명 종료일·시간대 미표기, 별 쏟아지는 들녘의 사진 확인 중 상태를 확인했습니다. 한국어 오현비파 상세는 320/360/390/768/1024/1440px에서 가로 넘침이 없었으며 닫기 전환 후 초점이 복원됐습니다. 브라우저 경고·오류 로그는 수집되지 않았습니다. [화면 기록](../../research/2026-10-19-ui/results.json).

새 파생 파일 8개의 합계는 전체 이미지 119,280바이트·썸네일 35,476바이트·선택기 5,876바이트·표시용 자르기 42,390바이트이며 첫 페이지 전송량 측정은 아닙니다. 실제 기기·Firefox/WebKit·200% 텍스트 확대·느린 네트워크·실사용 Core Web Vitals·한국 공식 카페 본문·전체 SNS 이력·현재 게임 내 획득 여부는 미검증입니다. 이번 제한된 점검에서 더 새로운 공식 외관 공지는 확인하지 못했습니다. 예상 이력·정기 예약·매거진 파일·공개 사이트 접근 범위는 유지하며 이미지 재사용 허가는 미확인입니다.
