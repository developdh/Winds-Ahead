# 0.3.10 — 중국 10월 16일 외관·글로벌 종료 시간대 보완

[English](../../en/releases/0.3.10.md) · [사이트](https://windsahead.com/ko) · [출처 점검](../content-review-2026-10-17.md) · [PR #51](https://github.com/developdh/Winds-Ahead/pull/51)

중국 공식 외관 9종의 가격을 구분하고 초 단위 종료 일정 5건을 추가했습니다. 강함추영·요공편영·죽풍답가·현영 무기 2종·낙월경홍·살면산군·분궐·동리고 고양이용/거위용 장식이 포함됩니다. 동료 장식은 각각 장명주 60개입니다. 확인한 사진 19장을 추가하고 가능한 여성 구도를 우선하며 확대에서 전체 사진을 제공합니다. 중국의 미표기 시간대·미발표 글로벌 대응은 미정으로 유지했고 지난 예고일만으로 실제 출시를 확정하지 않았습니다.

영문 개별 외관 공지의 UTC+8 근거를 기존 글로벌 종료 일정 5건에 연결해 그중 미정이던 시간대 3건을 보완했습니다. 나머지 미표기 시간대는 미정입니다. 도감은 외관 734종·외관 484종의 사진 846장·서버 기록 676건·글로벌 일정 231건·종료 일정 47건이며 빈 갤러리는 250종입니다.

검증: 타입 검사·도메인/미디어 테스트 44개·콘텐츠 검사·이전 예상 이력 보존 검사를 통과했습니다. 배포용 Worker 빌드도 통과했으며 기존 프레임워크·청크 경고는 남아 있습니다. 인앱 Chromium에서 신규 9종의 영어 1440px·한국어 390px 상세와 주요 사진 로딩·가로 넘침 없음을 확인했습니다. 헤어 상세는 320/360/390/768/1024/1440px에서도 확인했고 의상 확대에서 1080×1920 전체 사진이 로드됐습니다. 보완한 글로벌 종료 일정 5건 모두 한국어 화면에 UTC+8이 표시됐습니다. 빠르게 이동하는 동안 로컬 React Suspense/서버 렌더링 오류 1건이 기록됐으며 클라이언트 렌더링으로 복구돼 확인한 상세·사진은 로드됐습니다. 원인은 규명하지 못했습니다. 화면 검사 범위는 [브라우저 근거](../../research/2026-10-17-ui/results.json)에 기록합니다. 운영 의존성 보안 검사에서 알려진 취약점은 0건입니다.

신규 파일 용량은 썸네일 1,329,316바이트·전체 사진 6,152,196바이트·선택용 미리보기 71,718바이트입니다. 파일 전체 합계이며 첫 화면 전송량 측정값이 아닙니다. 한국 공식 카페 접근은 실패했고 공식 소셜 전체 이력·게임 내 상태·실물 기기·Firefox/WebKit·텍스트 200% 확대·실사용 성능은 미검증입니다. 사진 재사용 허가는 미확인이며 예상 이력·예약·매거진·사이트 공개 범위는 유지했습니다.
