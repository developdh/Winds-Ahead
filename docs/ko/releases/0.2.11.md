# Winds Ahead v0.2.11

[English](../../en/releases/0.2.11.md) · [출시 로드맵](https://windsahead.com/ko/calendar?view=timeline) · [PR #36](https://github.com/developdh/Winds-Ahead/pull/36)

**어룡의 불꽃 / Dragoncarp Blaze**를 **2026년 10월 4일 05:00(UTC+8), 한국시간 06:00** 글로벌 공명 상점 출시 예고로 추가했습니다. [영문 공식 공지](https://x.com/WhereWindsMeet_/status/2104541645068755437)에서 시간대를, [한국 공식 카페](https://cafe.naver.com/wherewindsmeet/2273)에서 한국어 명칭과 06:00 표기를 확인했습니다. 고유 소개 문구·승표 동작·금빛 물고기와 불꽃 연출을 대조해 기존 중국 鱼龙焰舞 항목 및 참고 사진과 연결했습니다.

Cloudgrace Earrings의 한국어 명칭을 [한국 공식 출석 공지](https://cafe.naver.com/wherewindsmeet/2269)에 나온 **서운 장식**으로 바로잡았습니다. 이전 음역으로도 검색할 수 있습니다. 9월 25일~10월 10일(UTC) 이벤트와 누적 출석 10일 조건은 유지하며, 장신구의 정확한 지급 일차는 미정입니다.

이펙트의 글로벌 가격·재화·교환 종료일은 미공개입니다. 중국 획득 조건은 별도로 유지하며 실제 출시를 확인했다고 표시하지 않습니다. 기존 운영자 예상 기간과 변경 이력을 보존했습니다. 기존 점검 절차에 따른 수동 확인이며 새 예약은 만들지 않았습니다. 일반 이벤트 포스터를 아이템 사진으로 추가하지 않았습니다.

[조사·출처 확인 기록](../../research/2026-09-29-official-refresh.json)

검증: 타입 검사, 테스트 46개, 콘텐츠 검사, 예상 이력 보존 검사, 배포용 빌드를 통과했습니다. Chromium에서 390px 한국어 로드맵·서운 장식 상세 화면, 1440px 영어 로드맵·어룡의 불꽃 상세 화면, 로드맵 상세 보기 연결, 중국·글로벌 획득 조건 분리, 이전 한국어 음역 검색을 확인했습니다. 가로 넘침은 없었습니다. 기존 빌드 경고는 남아 있으며 실제 기기와 Firefox/WebKit은 테스트하지 않았습니다.
