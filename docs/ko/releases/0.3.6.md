# 0.3.6 — 10월 11일 외관 예고와 공식 일정 표시 수정

[English](../../en/releases/0.3.6.md) · [사이트](https://windsahead.com/ko) · [출처 점검](../content-review-2026-10-07.md) · [PR #47](https://github.com/developdh/Winds-Ahead/pull/47)

숨겨진 선율-천상의 바람, 매화 끝의 봄, 설산의 매화, 나그네의 옷, 비휴의 축복에 공식 영어·한국어 이름과 10월 11일 글로벌 출시 예고·획득 가격을 반영했습니다. 설산의 매화의 2027년 1월 9일 교환 종료와 비휴의 축복의 11월 23일 할인 종료를 추가했습니다. 양언어 공지의 현지 시각을 구분하고 미표기 시간대는 미확인으로 유지합니다. 할인 종료를 판매 종료로 해석하지 않으며 다섯 항목 모두 출시 예고입니다.

확인한 중국 여성 참고사진 3장을 추가하고 헤어 미리보기를 여성 중심으로 조정했으며 전체 원본을 유지했습니다. 비휴의 축복에 잘못 연결된 사자 모자 사진을 해당 이펙트의 공식 사진으로 교체했습니다. 외관 720개에 사진 790개, 서버별 기록 648개, 글로벌 일정 216개, 종료 일정 29개입니다. 이미지 재배포 권한은 미확인입니다.

공식 날짜가 있는데도 카드에 “날짜 미정”이 표시되던 오류를 수정했습니다. 이전 예상용 인자가 남아 현재 날짜를 잘못 받던 문제였으며 테스트를 실제 화면과 같은 네 인자 방식으로 맞춰 미래·당일·지난 날짜·미정 상태를 검증했습니다. 예상 중단 정책과 감사 이력은 유지합니다.

[GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w)에 대응하여 sharp와 기존 miniflare override를 0.35.4에서 0.35.5로 갱신했습니다. 운영 의존성 보안 검사에서 취약점은 발견되지 않았습니다.

타입 검사, 도메인·미디어 테스트 44개, 콘텐츠·이력 검증과 배포 빌드가 통과했습니다. 앱 내 Chromium에서 한국어 상세 5개(390px), 영어 상세 5개(1440px)의 사진 로드, 이펙트 확대·닫기, 관련 카드 D-4 표시, 양언어 모바일 캘린더와 데스크톱 달력을 확인했습니다. 한국어 로드맵은 320/360/390/768/1024/1440px에서 다섯 항목과 가로 넘침 없음을 확인했습니다. 수집된 브라우저 오류는 없습니다. [화면 검증 기록](../../research/2026-10-07-ui/results.json).

한국어 카페는 접근 제한으로 확인하지 못했고 소셜 채널·게임 내 판매 여부는 별도 검증하지 않았습니다. 실제 기기, Firefox·WebKit, 글자 200% 확대와 실사용 성능은 미검증입니다. 기존 프레임워크·번들 경고는 남아 있습니다. 새 정기 작업이나 매거진 회차는 추가하지 않았습니다.
