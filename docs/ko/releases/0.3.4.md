# 0.3.4 — 공식 일정만 제공

[English](../../en/releases/0.3.4.md) · [사이트](https://windsahead.com/ko/calendar) · [정책](../official-schedules.md)

사용자 요청으로 운영자 출시 예상을 중단했습니다. 로드맵·캘린더의 예상·종류 필터·근거·공개 예상 이력, 도감의 예상 카운트다운, 소개·메타데이터의 예상 문구를 제거했습니다. 기존 `kind=forecast` 링크도 공식 기록을 표시합니다. 미발표 일정은 미정으로 두며 공식 일정·서버 사실·획득처·가격·갤러리·종료 정보는 유지합니다.

예상 8개 계열에 새 철회 기록을 추가하고 이전 기록은 모두 보존했습니다. 현재 점검 지침은 예상 생성·재활성화를 금지하고 이전 기획·조사 문서에도 현행 정책이 우선함을 명시했습니다. 새 정기 작업이나 자동 병합을 추가하지 않았습니다. 사용 가능한 예약 도구에서 기존 설정을 읽을 수 없어 예약 자체를 변경했다고 주장하지 않습니다.

매거진 창간호 수정판 5에서는 예상 기사·표지 언급·예상 지면을 제거했습니다. 양언어 공유판 6장은 표지·공식 예고 외관 네 가지·사이트 소개로 구성합니다. 이전 공유판은 공개 자산에서 제거하고 Git 이력에 보존하므로 이전 다운로드 주소는 종료합니다. 정정 기록은 남기며 이미 다운로드한 파일은 회수할 수 없습니다.

타입 검사·도메인/미디어 테스트 44개·콘텐츠/공유판 검증·기존 예상 이력 보존·루트 배포 빌드를 통과했습니다. Chrome에서 두 언어의 320·360·390·768·1024·1440px로 기존 예상 링크·캘린더·이전 예상 외관 상세·소개·매거진을 확인했습니다. 팝업 열기/Escape 닫기·월 이동·언어별 미리보기 6장 디코딩·ZIP 다운로드를 검증했고 가로 넘침·깨진 로드 이미지·페이지 오류는 없었습니다. 두 언어 표지와 소개 공유면을 시각 검토했습니다. 기존 프레임워크·큰 청크 경고는 남아 있으며 실제 기기·Firefox/WebKit·실사용 성능·커뮤니티 압축은 미검증입니다.
