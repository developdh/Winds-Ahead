# 0.2.4 — 출시 예상 재검토와 9월 공식 예고

[English](../../en/releases/0.2.4.md) · [사이트](https://windsahead.com/ko/calendar) · [전체 검토](../forecast-review-2026-09-21.md) · [Pull request #29](https://github.com/developdh/Winds-Ahead/pull/29)

기존 예상 3건의 최초 이력을 보존하고 재검토했습니다. 기간을 유지하면서 근거와 반대 사례를 갱신하고, 다음 검토일을 9월 28일로 정했습니다. 근거가 제한적인 현영 창의 10~11월 예상과 권갑의 10~12월 예상을 추가했습니다. 다른 후보 13종은 이유를 기록하고 미정으로 유지했습니다. 고정된 중국→글로벌 시차나 확률 점수는 사용하지 않습니다.

직접 읽은 영문·한국어 이미지 공지와 공식 X를 근거로 9월 25·27일 공식 예고 5종을 추가했습니다. 모두 기존 중국 외관과 대조해 공식 번역명·서버별 가격을 보강했고, 황금빛 설렘·떠오르는 달빛의 가벼운 미리보기를 넣었습니다. 미표기 시간대와 한국어 황금빛 설렘 종료일의 불일치는 그대로 구분해 남겼습니다. 실제 출시가 별도로 확인되기 전까지 공식 날짜는 예고 상태입니다.

검증: 타입 검사, 기존 도메인·미디어 테스트 36개, 콘텐츠 검증, 게시용 빌드가 통과했습니다. 최초 예상 3건이 그대로 보존됐으며 현재 로드맵 선택 결과는 예상 5건·공식 예고 5건입니다. 원문 패널·외관 대응·새 이미지 크롭을 시각적으로 확인했습니다. 화면 코드는 변경하지 않았으며 새로운 브라우저·기기·실사용 성능 검증을 주장하지 않습니다. 기존 빌드 경고는 남아 있습니다. 정기 점검 예약은 그대로 유지합니다.
