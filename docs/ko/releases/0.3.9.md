# 0.3.9 — 글로벌 2.3 버전 외관·한국어 공식명

[English](../../en/releases/0.3.9.md) · [웹사이트](https://windsahead.com/ko) · [출처 확인](../content-review-2026-10-14.md)

공식 2.3 버전 영문·한국어 공지로 글로벌 외관 15종을 보완했습니다. 10월 15·18일 외관 12종과 옥진의 메아리 보상 3종입니다. 금사의 잔영·작열의 금사를 글로벌 전용 항목으로 추가하고 기존 항목 13개를 연결했으며 15종의 영어·한국어 공식명을 확인했습니다. 교환 가격·강호령 선행 조건·의상과 고양이 조합 할인·무기별 가격·신규 종료 일정 7건을 보완했습니다. 중국 조건은 구분하며 미표기 시간대·미발표 날짜는 미확인, 해당 출시 상태는 예고로 유지합니다.

확인한 사진 영역 14개를 추출하고 출처 해시·정확한 좌표·출처 표기를 남겼습니다. 여성 미리보기 6개는 인물 중심 구도로 정돈했으며 확대에서는 전체 남녀 사진과 원본 공지 링크를 제공합니다. 핵심 설명은 짧게 유지하고 상세 획득 조건은 아래에 표시합니다. 재배포 권한은 미확인입니다. 도감은 외관 725개·475개 항목의 사진 827장·서버 기록 667개·글로벌 일정 231개·종료 일정 42건입니다.

검증: 타입 검사·도메인/미디어 테스트 44개·콘텐츠 검증·이전 예상 이력 보존·저장소 루트 프로덕션 Worker 빌드를 통과했습니다. 준비 중 미디어 테스트가 헤어 자르기 높이 기록 오류를 발견했으며 최종 수정본은 통과했습니다. 앱 내 Chromium으로 15종 전체의 영문 1440px·한국어 390px 상세, 기본 사진 로드와 별 쏟아지는 들녘의 사진 확인 중 표시를 확인했습니다. 한국어 로드맵·캘린더는 320px로 확인했고 로드맵에는 예고 15종이 표시됐습니다. 페이지 가로 넘침은 없었습니다. 금사의 잔영 확대는 전체 남녀 사진 924×858과 원본 공지 링크를 유지했습니다. 확인한 브라우저 탭에서 경고·오류가 수집되지 않았습니다. 새 에셋 합계는 썸네일 684,364바이트·전체 사진 1,490,218바이트·선택 미리보기 34,318바이트·표시용 자르기 438,628바이트이며 초기 페이지 전송량 측정값이 아닙니다. 기존 프레임워크·청크 빌드 경고가 남아 있습니다. 첫 샌드박스 미리보기는 Windows 런타임 권한 검사에서 실패했으며 권한이 부여된 로컬 미리보기는 정상 실행됐습니다. 이동 직후 즉시 누른 첫 갤러리 클릭에는 변화가 없었으나 DOM 확인 후 다시 누르자 확대창과 사진이 로드됐습니다. 첫 클릭의 원인은 확정하지 못했습니다. 실기기·Firefox/WebKit·글자 200% 확대·저속 네트워크 성능·현장 Core Web Vitals·게임 내 획득 가능 여부·카페/X 전체 이력은 미검증입니다. 예상 이력·정기 예약·매거진·사이트 공개 범위는 변경하지 않았습니다.
