# Winds Ahead v0.2.0

[English](../../en/releases/0.2.0.md) · [웹사이트](https://windsahead.com) · [변경 PR](https://github.com/developdh/Winds-Ahead/pull/25)

서버 필터·날짜와 이름 정렬에 더해 **획득처로 외관을 찾는 기능**을 추가했습니다. 불길에 단련된 철골의 잘못된 사진 연결을 수정하고 9월 14일 글로벌 공식 외관 공지도 반영했습니다.

## 변경 사항

- 상점·공명/추첨·음옥 상점·강호령·이벤트·플레이/누적 보상·기타 교환·획득처 확인 중을 선택할 수 있습니다. 서버 필터·정렬과 조합하고 언어 변경·상세 팝업에서도 유지합니다. 카드 가격도 필터와 같은 서버의 정보를 사용합니다.
- **불길에 단련된 철골 / Forged in Fire**의 외관 연결 오류를 수정했습니다. 불꽃 투구 갑옷과 글로벌 획득 정보를 별도 기록으로 분리하고, 다른 중국 의상인 붉은 천 의상은 원래 중국 기록으로 보존했습니다.
- **찬 물결·무생의 독충·천수관음·허공의 물결** 등 한국어 공식명 8종과 새 영문 공식명 6종을 반영했습니다. 기존 한국어 독음으로도 검색할 수 있습니다.
- 9월 16일 글로벌 출시 예정 6종을 추가하고 기존 2종도 보강했습니다. 8종 모두 예정으로 유지하며 출처별 시간 표현과 미공개 글로벌 가격을 구분했습니다.
- 다른 각도의 최적화 사진 3장을 추가했습니다. 현재 **외관 기록 686개, 외관 371종의 사진 557장**을 제공합니다.

## 검증 및 한계

타입 검사, 도메인·미디어 테스트 **36개**, 콘텐츠 검증, 예상 이력 보존 검사, 배포용 빌드를 통과했습니다. 한영 화면에서 필터 조합·정렬·빈 결과 초기화·언어 변경·팝업 종료와 새로고침·이전 이름 검색·수정된 철골 사진을 확인했습니다. 320·360·390·768·1024·1440px에서 가로 넘침 없이 표시됐고 필터 높이는 44px을 유지했습니다. Codex 내장 Chromium 브라우저에서 모바일·데스크톱 화면을 살펴봤습니다.

이번 업데이트에서 실제 모바일 기기, Firefox/WebKit, 느린 네트워크·실사용 성능 검증은 하지 않았습니다. 기존 큰 번들 경고는 남아 있습니다. 새 글로벌 공지를 중심으로 확인했으며 X 전체 게시물을 수집한 것은 아닙니다. 미공개 가격·실제 출시 확인·이미지 재배포 허가는 미정으로 유지합니다.
