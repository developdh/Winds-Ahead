# 0.3.15 — 중국 10월 23일 외관·보상 장신구

[English](../../en/releases/0.3.15.md) · [웹사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-10-25.md) · [PR #56](https://github.com/developdh/Winds-Ahead/pull/56)

중국 외관 예고 9종을 추가했습니다. 의상 2종·헤어 1종·무릉고 무기 외관 1종·보상 장신구 5종의 서버별 가격·구성품·무기 구매 횟수별 할인과 직접 명시된 획득 경로 종료 8건을 기록했습니다. 주요 종료 3건은 80일·90일을 계산하지 않고 패치 이미지가 명시한 날짜를 사용합니다. 뽑기 풀 종료와 별도 보상 수령 만료를 구분합니다. 미표기 시간대·개별 보상 지급일·현재 게임 내 획득 여부·미발표 글로벌 일정은 미확인으로 유지합니다. 영문·한국어 명칭은 임시 독음이며 기존 10월 25일 글로벌 등록은 유지합니다.

여성 의상·헤어 사진, 확인된 무기 구도와 명칭별 장신구 도해를 포함한 참고 사진 14장을 추가했습니다. 특징을 중심으로 표시하며 확대에서 선택한 구도 전체를 보존하고 전체 원본 포스터를 연결합니다. 최적화한 파생 파일 56개의 출처·자르기 좌표·용량·해시를 기록했습니다. 장신구 5종의 캐릭터 착용 사진과 사진 재배포 허가는 미확인입니다. 최종 수량은 외관 750개·외관 504종의 사진 886장·빈 갤러리 246개·서버별 기록 700개·글로벌 일정 241개·종료 일정 74개입니다.

프로덕션 감사에서 새 보안 공지가 보고되어 Zod를 3.25.76에서 4.6.7로, fast-uri를 3.1.8에서 3.1.9로 올렸습니다. Zod 4에 맞게 레코드 검증 2곳에 문자열 키 스키마를 명시했으며 기존 resolver의 호환 조건을 충족합니다. 갱신 후 프로덕션 감사의 영향 패키지는 0개이며 실제 런타임 공격 가능성을 확인한 것은 아닙니다. [의존성 검토·보안 공지 원문](../../research/2026-10-25-dependency-review.json).

검증 통과: TypeScript·기존 테스트 44개·콘텐츠/사진/출처·예상 이력 보존·저장소 루트 프로덕션 Worker 빌드. 별도 콘텐츠 검토에서 외관 9종·종료 8건·파생 사진 56개의 해시가 근거와 일치했습니다. 기존 프레임워크·설정·대형 청크 경고는 남아 있습니다.

인앱 Chromium에서 주요 외관 4종과 황금안 도해의 한국어 390px 상세, 의상의 영어 1440px 상세를 확인했습니다. 헤어 상세는 320/360/390/768/1024/1440px에서 가로 넘침이 없습니다. 의상·도해의 확대 구도와 원본 링크를 확인했습니다. [화면 검증 기록](../../research/2026-10-25-ui/results.json). 실물 기기·Firefox/WebKit·200% 텍스트 확대·느린 네트워크·실사용 Core Web Vitals·한국 공식 카페 본문·전체 소셜 이력·현재 게임 내 획득 여부는 미확인입니다. 예상 이력·기존 예약·매거진 공유판·사이트 공개 범위는 유지합니다.
