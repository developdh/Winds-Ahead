# 0.2.5 — 공식 일정 우선 정렬과 이미지 잘림 수정

[English](../../en/releases/0.2.5.md) · [웹사이트](https://windsahead.com/ko/calendar) · [이미지 보정 기록](../../research/2026-09-23-image-framing.json) · [PR #30](https://github.com/developdh/Winds-Ahead/pull/30)

로드맵에서 공식 일정을 모두 먼저 보여주고, 운영자 예상은 별도 제목과 비공식 표시를 붙여 뒤에 배치합니다. 예상 기간의 시작이 빨라도 공식 일정 앞에 나오지 않습니다. 날짜·근거·변경 이력·필터의 의미는 유지합니다.

사막의 독충술의 잘린 오른쪽 테두리를 포함해 기존 공식 포스터 이미지 132개의 구도를 보정하고 이전 자르기 좌표를 기록에 남겼습니다. 상세·빠른 보기에서는 전체 이미지를 사용하며 포스터 카드와 사진 선택 목록도 양쪽 인물을 보존합니다. 사진 선택용 582개 미리보기를 별도로 작게 만들어 세로형 잘라내기를 없앴습니다. 갤러리는 전체 맞춤으로 열리고, 필요할 때 확대해 가로·세로로 스크롤할 수 있습니다. 사진을 바꾸면 확대가 초기화되며 사진 비율이 달라도 화면 영역은 안정적으로 유지됩니다.

검증: 타입 검사, 도메인·미디어 테스트 38개, 콘텐츠 검증과 프로덕션 Worker 빌드를 통과했습니다. 앱 내 Chromium에서 영어·한국어, 320/360/390/768/1024/1440 CSS px 갤러리 크기, 전체 맞춤·확대, 사진 이동, 방향키, 닫기·포커스 복귀, 로드맵 구역·필터를 확인했습니다. 전체 이미지와 선택용 미리보기 비율은 자동 검증하고 포스터 132개의 원본 경계는 비교 이미지로 시각 확인했습니다. 선택용 파일 582개의 합계는 약 1.76MB이며 필요한 곳에서만 로드합니다. 기존 Vite 설정·번들 크기 경고는 남아 있습니다. Firefox/WebKit·실물 기기·느린 네트워크·실사용 성능은 측정하지 않았습니다.
