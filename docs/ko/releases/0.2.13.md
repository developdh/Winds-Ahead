# Winds Ahead v0.2.13

[English](../../en/releases/0.2.13.md) · [웹사이트](https://windsahead.com/ko) · [PR #38](https://github.com/developdh/Winds-Ahead/pull/38)

**참고 사진 117장**을 추가했으며, 이 중 **102장은 기존 의상 28종**의 사진입니다. 비어 있던 상사곡·염청창·산중인·유란로·맹주가도·오풍청 갤러리 6곳에 여성 정면·후면 사진을 채웠습니다. 중국 공식 의상 9종에 인물·후면·세부·재단 사진 64장, 커뮤니티 의상 19종에 출처를 표시한 착용 사진 38장을 추가했습니다. 확인 가능한 여성 미리보기를 우선하고 전체 구도·워터마크를 보존했으며 작은 WebP 썸네일과 선택용 이미지를 제공합니다.

[중국 공식 10월 2일 신규 외관](https://www.yysls.cn/news/official/20260930/37780_1315695.html) 3종과 사진 15장을 등록했습니다. 주란고청(朱鸾顾晴)은 장명주 300개·정가 680개, 장음·천지일소(藏音·天地一啸)는 기본 형태 팔음규 1개·360일 판매, 만뢰·축월산(万籁·逐月霰)은 장명주 1,280개입니다. 한글명은 임시 독음이며 모두 출시 예고로 표시합니다. 10월 2일 00:00:00의 시간대와 정확한 교환 종료 시각은 미확인입니다.

9월 30일 [영문 공식 공지](https://www.wherewindsmeetgame.com/news/official/1004appearance.html)에서 글로벌 외관 4종의 10월 4일 출시 시각을 **05:00 UTC+8 / 한국 시간 06:00**으로 확인했습니다. 영문 광명의 길 제목의 복사 오류는 본문과 [한국어 공지](https://www.wherewindsmeetgame.com/kr/news/official/1004appearance.html)로 구분했습니다. 불꽃 축제의 밤 할인 종료 문장에는 시간대가 명시되지 않아 미정으로 유지했습니다. 중국·글로벌 사진이 섞인 갤러리는 로드맵에서 실제 선택된 사진의 서버를 표시합니다.

[사진별 출처·갤러리 전후 수량·검토 및 수집 한계](../../research/2026-09-30-archive-photos.json)를 기록했습니다. 커뮤니티 사진만으로 글로벌 공식명·출시·획득 정보를 확정하지 않았으며 재사용 허가 상태는 미확인입니다. 기존 예상 이력과 정기 일정은 유지했습니다.

타입 검사, 도메인·미디어 테스트 46개, 콘텐츠 검증, 예상 이력 보존 검사와 배포용 Worker 빌드를 통과했습니다. 라이선스가 있는 두 글꼴 서브셋을 다시 생성했습니다. Chromium에서 새로 채운 커뮤니티 갤러리의 확대·다음 사진·닫기(390px), 기존 의상 15장 갤러리(390px), 신규 중국 의상 8장과 출시 예고·할인 가격(1440px)을 확인했습니다. 검사한 화면에는 깨진 로드 이미지·가로 넘침·브라우저 오류가 없었습니다. 기존 프레임워크·큰 청크 경고는 남아 있으며 실제 기기와 Firefox/WebKit은 검사하지 않았습니다.
