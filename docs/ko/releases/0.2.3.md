# 0.2.3 — 영혼의 각인 미리보기 개선

[English](../../en/releases/0.2.3.md) · [사이트](https://windsahead.com/ko?item=ying-hun-zhao-gu) · [공식 X 출처](https://x.com/WhereWindsMeet_/status/2100585570816737364)

확대한 공홈 GIF의 거친 정지 화면을 공식 X의 2400×1080 영상에서 고른 선명한 장면으로 교체했습니다. 붉은색·금색 무술 효과를 보여 주고 원본 장면과 크롭 정보를 기록합니다. 자동 재생 없이 가벼운 정적 WebP 이미지를 사용합니다.

사용자가 로그인한 뒤 공식 X 게시물을 직접 확인했습니다. 9월 20일 05:00 UTC+8 출시 예고는 공홈과 일치하며, 이번 사진 수정으로 출시 상태·가격·중국 외관 연결은 바꾸지 않습니다. 미디어 재사용 권한은 미확인입니다.

검증: 타입 검사, 도메인·미디어 테스트 36개, 콘텐츠 검증, 배포 빌드를 통과했습니다. 선택 장면과 세로형 썸네일을 직접 확인했으며 썸네일은 33 KB, 확대 이미지는 50 KB입니다. 이번에는 별도의 브라우저·기기·성능 측정을 하지 않았습니다. 기존 번들 경고는 남아 있습니다.
