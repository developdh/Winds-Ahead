칼을 문 푸른 새·맑은 물결의 빈 갤러리에 확인한 공식 사진을 추가했습니다. 공식 한국어 이름을 등록하고 가격 미표기라는 설명을 공식 할인 가격 음옥 2개로 정정했으며 과거 7월 26일 판매 종료를 추가했습니다. 영어·한국어 현지 시각은 구분하고 시간대·정상가·현재 재판매 여부는 미확인입니다. 미리보기는 테두리를 제거하고 확대에는 개별 그림 전체를 보존하며 전체 원본 포스터를 출처로 연결합니다. 재배포 권한은 미확인입니다.

10월 6일 중국·영어·한국어 공식 목록에는 기존 기록 이후 새 외관 예고가 없었습니다. 중국 10월 3일 기사는 풍경 배경화면입니다. 10월 4일 외관은 예고 상태를 유지하며 게임 내 확인은 주장하지 않습니다. 한국 공식 카페 접근에 실패했습니다. Glassy Expanse는 사진을 확실히 식별하지 못해 빈 갤러리를 유지합니다. 예상이나 정기 작업은 추가하지 않았습니다.

타입 검사·도메인/미디어 테스트 44개·콘텐츠 검증·과거 예상 이력 보존·루트 배포 빌드를 통과했습니다. 로컬 Chrome 헤드리스에서 두 외관의 영어 1440px·한국어 390px 상세를 확인하여 이름·가격·이미지 로드·가로 넘침 없음·페이지 오류 없음을 검증했습니다. 출처 그림과 최종 미리보기도 시각 검토했습니다. 실제 기기·Firefox/WebKit·실사용 성능·현재 게임 내 판매는 미검증이며 기존 프레임워크·청크 경고는 남아 있습니다.
