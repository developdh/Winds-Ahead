# 0.2.7 — 9월 외관·중추절 보상 갱신

[English](../../en/releases/0.2.7.md) · [사이트](https://windsahead.com) · [PR #32](https://github.com/developdh/Winds-Ahead/pull/32) · [조사 범위와 한계](../official-refresh-2026-09-26.md)

중국 외관 13종·글로벌 이벤트 장신구 2종·직접 확인한 정적 이미지 20개를 추가하고 여성 외형을 우선합니다. 기존 글로벌 일정 5종의 UTC+8 근거를 보강하고 황금빛 설렘의 10월 25일 종료를 재확인했습니다. 흑선의 울림의 할인 종료와 판매 종료, Cloudgrace Earrings의 이벤트 기간과 미정인 지급 일차를 구분합니다.

중국 신규 4종은 게임 내 수정 공지로 확인했으며, 나머지는 날짜 경과만으로 출시 확인으로 바꾸지 않습니다. 임시 한국어 명칭·미확인 사진·미확인 글로벌 대응을 구분합니다. 기존 예상 5건·수정 이력 8개·검토 기한을 유지합니다.

검증: 타입·도메인 및 미디어 검사 41개·콘텐츠·예상 이력·프로덕션 Worker 빌드. Chrome에서 한국어 신규 의상 화면을 320/360/390/768/1024/1440 CSS px로 확인해 가로 넘침이 없었습니다. 모바일 전체 이미지 열기·닫기, 언어 전환, 390px 영어 사진·보상일 미확인 상태, 한국어 모바일 캘린더·서버 전환과 예상 5건 유지를 확인했습니다. 배포 결과는 별도로 기록합니다. 기존 Vite 설정·번들 크기 경고가 있으며 실제 기기·현장 성능은 측정하지 않았습니다.
