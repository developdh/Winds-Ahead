# 연운경 v0.3.3

[English](../../en/releases/0.3.3.md) · [창간호](https://windsahead.com/ko/magazine/issue-01) · [PR #44](https://github.com/developdh/Winds-Ahead/pull/44)

공유판 마지막에 짧은 연운경 소개 면을 추가했습니다. 외관 도감·로드맵·매거진에서 볼 수 있는 정보, 큰 windsahead.com 주소, 독립 팬 프로젝트 표시를 담습니다. 기존 정보 지면 여섯 장의 내용은 유지하며 현재 다운로드를 언어별 JPG 일곱 장·갱신된 페이지 번호·ZIP으로 교체합니다. 수정판 4는 이전 파일·공식 사실·출처 표시·예상 이력을 보존합니다.

타입, 기존 테스트 46개, 콘텐츠·내보내기·예상 이력 검증과 루트 빌드를 통과했습니다. Chrome 한국어 320/390px·영어 360/1440px에서 미리보기 일곱 장, ZIP, 회차 이동, 언어 전환, 출처, 메타데이터·사이트맵과 미존재 회차 404를 확인했고 가로 넘침·깨진 로드 이미지·페이지 오류가 없었습니다. 마지막 소개 면을 두 언어로 시각 검토했습니다. 기존 프레임워크·큰 청크 경고는 남아 있으며 실제 기기·커뮤니티 업로드 압축·실사용 성능은 검증하지 않았습니다.

[제작 정책](../magazine.md)과 [UI 검증](../../research/2026-10-01-magazine-about-ui/results.json)을 참고합니다.
