# 0.3.12 — 공식 보상 외관·참고 사진 보완

[English](../../en/releases/0.3.12.md) · [웹사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-10-18.md)

영문·한국어 공식명을 확인한 기존 누락 글로벌 외관 5종, 총명한 파·약초 향기·귓가의 신령·하늘의 뜻·손댈 수 없는 미소를 추가했습니다. 이벤트 종료 2건을 추가하고 개별 요구 조건·중국 대응·출시일은 미정으로 유지합니다. 시험장의 암투는 영문·한국어 시작일이 달라 양쪽 관측과 확인된 종료 시각을 획득 설명에 보존하며 단일 캘린더 날짜를 만들지 않습니다.

기존 중국 등불 2종의 갤러리, 개별 장명주 300개·별도 360개 소유/선물 전용 상자 조건과 과거 판매 종료 2건을 보완했습니다. 근거가 부족한 출시 확인을 확인 대기 예고로 정정하며 명시된 과거 판매 예고일을 보존합니다. 긴 꿈속의 별 여성 앞·뒤와 남성 뒤 모습을 포함해 참고 사진 7건을 추가하고 전체 원본 접근·자르기 근거·개발 중 조건·재배포 허가 미확인을 유지합니다. 총 외관 739개·외관 491종의 사진 858장·서버 기록 681개·글로벌 일정 231개·종료 일정 56개이며 빈 갤러리는 248개입니다.

타입 검사·전체 44개 테스트·콘텐츠/사진/참조 검증·예상 이력 보존·저장소 루트의 프로덕션 Worker 빌드를 통과했습니다. 과거 예고 검사가 확인 대기 항목의 날짜를 모두 미정으로 가정해 처음 실패했으며, 근거 있는 과거 예고일은 허용하되 출시 확인·미래 해석을 거부하도록 수정했습니다. 배포 패키지 보안 검사는 알려진 취약점 0건입니다. Sites 빌드 래퍼는 Windows npm 실행 경로 문제로 실패했으나 기존 루트 빌드는 성공했습니다. 기존 프레임워크·청크 크기 경고는 남아 있습니다.

앱 내 Chromium에서 한국어 390px·영어 1440px로 영향받은 상세 8종, 3개 갤러리 로드, 여성 우선 헤어 사진·사진 미확인 상태·이벤트 시작일 차이·등불 가격을 확인했습니다. 한국어 귀걸이 상세는 320/360/390/768/1024/1440px에서 가로 넘침이 없었습니다. 화면 상태를 기다려 갤러리 이동·원본 링크·닫기·초점 복원을 확인했으며 브라우저 경고·오류 로그는 수집되지 않았습니다. [화면 검증 기록](../../research/2026-10-18-ui/results.json).

새 파생 파일 합계는 전체 이미지 1,579,730바이트·썸네일 285,162바이트·선택기 미리보기 18,368바이트·표시용 자르기 392,984바이트입니다. 합계 용량이며 첫 화면 전송량 측정이 아닙니다. 실제 기기·Firefox/WebKit·200% 확대·느린 네트워크 성능·한국 카페 본문·전체 소셜 이력·현재 게임 내 획득 여부는 미확인입니다. 예상 이력·기존 예약·매거진 내보내기·공개 범위는 유지합니다.
