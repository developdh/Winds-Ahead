# Winds Ahead v0.2.8

[English](../../en/releases/0.2.8.md) · [사이트](https://windsahead.com) · [검토](../forecast-gallery-2026-09-28.md) · [PR #33](https://github.com/developdh/Winds-Ahead/pull/33)

- 보추정·만뢰 계열 무기 2종의 제한적 글로벌 예상을 추가해 현재 로드맵 예상이 8건이 됐습니다.
- 기존 예상 5건은 기간과 모든 과거 이력을 보존해 재검토했습니다. 다음 검토일은 10월 5일입니다.
- 외관 4종에 공식 여성형 사진 6장을 더하고 중국 공지의 명시 날짜 1건을 보완했습니다. 외관 716종·이미지 참조 608개입니다.
- 확인한 최신 공식 공지와 글로벌 SNS에서는 추가 외관 일정을 식별하지 못했습니다. 확인 범위와 예상의 불확실성을 기록했습니다.

검증: 타입 검사·테스트 41개·콘텐츠 검증·예상 이력 보존·운영 Worker 빌드가 통과했습니다. 브라우저에서 한국어 390px의 로드맵·캘린더 예상 8건과 새 사진으로의 갤러리 이동, 영어 320px의 신규 후보 이름·표시·가로 넘침 없음을 확인했습니다. 해당 화면에서 로딩된 이미지의 깨짐은 없었습니다. 실제 모바일 기기·Firefox/WebKit·실사용 성능은 미검증이며 큰 번들과 향후 Vite 설정 로딩에 관한 기존 빌드 경고는 남아 있습니다. 새 예약·자동 병합은 추가하지 않았습니다. 미디어 재배포 권한은 미확인이며 코드 라이선스에서 제외합니다.
