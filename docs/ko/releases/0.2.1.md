# 0.2.1 — 불길에 단련된 철골 사진 교체

[English](../../en/releases/0.2.1.md) · [웹사이트](https://windsahead.com/ko?item=global-forged-in-fire) · [풀 리퀘스트 #26](https://github.com/developdh/Winds-Ahead/pull/26) · [공식 원본 영상](https://x.com/WhereWindsMeet_/status/2093700198639783937)

**불길에 단련된 철골** 갤러리의 대표 사진을 기존 공지 포스터 크롭에서 글로벌 공식 4K 외관 영상의 더 선명한 전신 장면으로 교체했습니다.

## 변경 사항

- 회색 배경에서 갑옷 실루엣과 전신이 또렷한 장면을 새 대표 사진으로 적용했습니다.
- 불꽃이 비치는 두 체형의 전신 참고 사진을 각각 추가했습니다.
- 빛나는 새 장식, 붉은 천, 흉갑의 문양을 볼 수 있는 디테일 사진을 추가했습니다.
- 글로벌 공식 출처, 미확인 재사용 허가, 중국·글로벌 외관의 기존 분리 기록을 그대로 유지했습니다.
- 네 장 모두 정적 WebP로 최적화했습니다. 첫 썸네일은 34KB이며 확대 사진 네 장의 합계는 약 217KB입니다.

## 검증

타입 검사, **도메인·미디어 테스트 36개**, 콘텐츠 검증과 프로덕션 빌드가 모두 통과했습니다. 로컬 프로덕션 빌드의 한국어 상세 팝업에서 사진 네 장과 `1 / 4` 표시가 나타나는지, 이전·다음 이동 시 선택 사진이 바뀌는지, 1280×720 화면에서 새 대표 사진의 전신이 유지되고 글자나 조작 버튼이 겹치지 않는지 확인했습니다.

## 한계

이번 사진은 중립적인 게임 내 의상실 캡처가 아니라 공식 홍보 영상에서 추출한 장면입니다. 재사용 허가는 확인되지 않았으므로 코드 라이선스와 분리된 참고 이미지로 유지합니다.
