# 0.3.19 — 방문자 정보를 유지한 배포 용량 여유 확보

[English](../../en/releases/0.3.19.md) · [웹사이트](https://windsahead.com/ko) · [근거](../../research/2026-11-02-compact-visitor-data.json) · [PR #60](https://github.com/developdh/Winds-Ahead/pull/60) · [이전 릴리스](0.3.18.md)

v0.3.18은 256 MiB 배포 제한 아래 여유가 491,520바이트뿐이었습니다. 이번 수정은 빌드에서 생성하는 방문자 데이터의 반복 필드명·문자열을 줄입니다. 크기를 제한한 생성 함수가 값·속성 순서가 같은 독립적인 일반 객체·배열을 만들며, 기준 조사 자료는 Git에 보존합니다. 도감·서버별 기록·번역·일정·출처 표시·매거진 정보의 의미와 동작은 유지합니다.

표준 형식 tar의 압축 해제 용량은 267,943,936바이트에서 265,488,896바이트로 줄었습니다. 2,455,040바이트를 절약해 여유가 2,946,560바이트로 늘었습니다. 배포되는 사진·글꼴·매거진·위키 파일 3,404개 모두 v0.3.18과 경로·SHA-256 해시가 같습니다. 이미지·인코딩·이전 공개 주소·다운로드를 보존합니다. 이후 갱신도 압축 파일 사전 검사가 필요합니다.

생성된 전체 클라이언트 JavaScript는 원래 용량 기준 2,959,649바이트에서 1,959,470바이트로, 파일별 gzip 용량의 합은 555,943바이트에서 536,110바이트로 줄었습니다. 지연 로드 청크도 포함한 합계입니다. 초기 페이지 전송량·실측 로딩 속도·Core Web Vitals 결과가 아닌 빌드 용량 비교이며, 초기 JavaScript 200 KB 목표는 아직 입증되지 않았습니다.

타입, 테스트 52개, 콘텐츠·사진·출처 검증, 예상 이력 불변과 저장소 루트 Worker 빌드를 통과했습니다. 모든 변환 대상 콘텐츠의 값 복원, 속성 순서, 특수 JSON 키와 중첩 객체·배열의 독립성을 검사했고 독립 검토에서 차단 문제를 찾지 못했습니다. 로컬 운영 빌드를 인앱 Chromium에서 열어 1440px·390px 영어·한국어 화면, 검색과 언어 변경 시 검색어 보존, 상세·갤러리 이동과 대응 원본 링크, 한국어 로드맵, 언어 변경 시 캘린더 월·모드 보존을 확인했습니다. 한국어 모바일 상세에 가로 넘침이 없었으며 콘솔 오류도 관찰되지 않았습니다. [브라우저 근거](../../research/2026-11-02-compact-visitor-data.json)에 화면과 속도 제한 없는 조건을 기록합니다. GitHub 릴리스와 실제 Site 발행은 별도로 확인합니다.

10월 31일 공식 출처 점검과 콘텐츠는 그대로입니다. 외관 755개, 외관 509개에 사진 905개, 서버별 기록 714개, 글로벌 일정 252개와 종료 일정 78개를 유지합니다. 실제 기기·Firefox·WebKit·200% 확대·느린 네트워크·실사용 성능·미디어 재배포 허가의 기존 확인 한계는 남습니다. 예상 이력·정기 예약·매거진 공유 파일도 유지합니다.
