# 0.3.16 — 10월 말 외관과 강호령 종료 변경

[English](../../en/releases/0.3.16.md) · [사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-10-31.md) · [PR #57](https://github.com/developdh/Winds-Ahead/pull/57)

10월 29일·11월 1일·11월 8일 글로벌 외관 11종의 한영 공식명·서버별 획득 조건을 추가했습니다. 검수한 사진으로 9종을 중국 항목에 연결하고 장신구 2종은 별도로 유지했습니다. 중국 10월 30일 예고 3종도 편의 독음·확인한 가격과 함께 추가했습니다. 판매·교환·할인 종료 4건은 명시·미정 시간대를 구분합니다. 연꽃 위의 학 할인 종료·장신구 패키지 가격은 미정이며 흑옥 시작 시각의 출처 간 불일치를 명시합니다.

10월 29일 패치에 따라 쓸쓸한 단풍 종료를 2026년 11월 13일 17:59:59 UTC+8로 수정하고 이전 관측·한국어의 시간대 미표기를 보존했습니다. 중국 과거 원문 전체를 다시 읽고 사전 예고만 확인된 출시 상태 8건을 출시 확인 중으로 바로잡았습니다. 별도 개별 패치로 세성방삭·도무상이 10월 30일까지 존재함을 뒷받침하지만 정확한 최초 출시일은 미정입니다. 세성방삭의 새 재단 스타일도 반영했습니다.

검수한 참고 이미지 19개·정지 WebP 파생 파일 76개를 추가했으며 합계 6,057,058바이트입니다. 사용 가능한 여성 구도를 우선하고 확대에서 전체 선택 구도·원본 링크를 보존합니다. 검증에서 발견한 중국 사진 선택 이미지 비율도 수정했습니다. 외관 755개, 외관 509종의 참고 이미지 905개, 빈 갤러리 246개, 서버 기록 714개, 글로벌 일정 252개, 종료 일정 78개입니다.

타입 검사·테스트 44개·콘텐츠·미디어·출처 검증·예상 이력 보존·프로덕션 취약점 0건·루트 배포 빌드가 통과했습니다. 독립 검토에서 이름·가격·상태·날짜·중복·출처·버전과 파생 파일 76개 해시·용량을 확인했습니다. 인앱 Chromium에서 상세 14종을 한국어 390px·영문 1440px로 확인했으며 대표 이미지가 로드되고 가로 넘침이 없었습니다. 긴 한국어 무기명은 320/360/390/768/1024/1440px에서 맞았습니다. 중국 확대 갤러리 이동·대응 원본 링크·초점 복귀, 10월·11월 글로벌 11종 연결, 한국어→영문 전환 시 월·캘린더 보기 유지, 변경된 강호령 종료 표시도 확인했습니다.
