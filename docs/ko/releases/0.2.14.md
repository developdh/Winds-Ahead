# Winds Ahead v0.2.14

[English](../../en/releases/0.2.14.md) · [웹사이트](https://windsahead.com/ko)

[중국 공식 10월 1일 업데이트](https://www.yysls.cn/news/update/20260930/40412_1315694.html)의 보상 배너와 교환 문단을 근거로 이벤트 발식 **抚虹鬓 / 무홍빈**을 추가했습니다. 심채결영(寻彩决英)에서 빈채화(缤彩花)를 모아 빈채 상점(缤彩商店)에서 교환하며, 10레벨과 청하 메인 장 又见新来燕 완료가 필요합니다. 이벤트는 10월 1일 05:00:00부터 10월 16일 04:59:59까지입니다. 시간대·필요 토큰 수량·별도 상점 종료일은 미확인입니다. 이벤트 종료와 상점 종료를 구분하며 글로벌 공식명·일정은 미정입니다. 무홍빈은 중국 원명의 임시 독음입니다.

목록에는 외관명과 테두리를 보존한 보상 배너를 표시하고 확대 시 공식 업데이트 공지 전체를 제공합니다. WebP 썸네일은 약 13 KB, 선택용 이미지는 1.5 KB입니다. 미디어 재사용 권한은 미확인입니다. 출처 제목을 원문대로 10월 1일 업데이트로 정정했고 게시일은 9월 30일로 유지했습니다. 기존 예상 이력과 글로벌 10월 4일 기록은 변경하지 않았습니다.

Windows 이미지 테스트가 파일 URL을 올바른 파일 경로로 변환하도록 수정했습니다. 기존에는 `/C:/...` 경로 때문에 파일이 존재해도 이미지 검사 4개가 실패했습니다. 새 명칭을 위해 기존 라이선스의 글꼴 서브셋도 재생성했습니다.

Windows에서 타입 검사·테스트 46개·콘텐츠 검증·배포용 빌드가 통과했습니다. Chrome의 한국어 390px·영어 1440px 화면과 전체 공지 확대·닫기 동작을 확인했고 로드된 이미지 오류·가로 넘침·페이지 오류는 없었습니다. 기존 프레임워크·큰 번들 경고는 유지됩니다. 실제 모바일 기기와 Firefox/WebKit은 테스트하지 않았습니다. 한영 README 수치를 외관 기록 720개·외관 467종의 사진 785장으로 갱신했습니다.

검토 후 통합과 CI 성공을 기다리는 다음 릴리스 준비 문서이며, 발행 완료를 뜻하지 않습니다. [점검 기록](../../research/2026-10-01-official-review.json), [한국어 모바일 화면](../../research/2026-10-01-ui/ko-390.png), [영어 데스크톱 화면](../../research/2026-10-01-ui/en-1440.png)을 참고하세요.
