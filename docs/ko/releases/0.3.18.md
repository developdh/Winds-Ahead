# 0.3.18 — 이전 전체 사진 주소 보존

[English](../../en/releases/0.3.18.md) · [웹사이트](https://windsahead.com/ko) · [배포 수정](0.3.17.md) · [근거](../../research/2026-10-31-legacy-photo-urls.json) · [PR #59](https://github.com/developdh/Winds-Ahead/pull/59)

로컬 Wrangler에서는 301을 반환했지만 실제 호스팅은 v0.3.17의 `_redirects` 파일을 적용하지 않았습니다. 공개 확인 중 이전 호박등 전체 사진 주소가 404를 반환했습니다. 이전 전체 사진 네 개를 실제 호환 파일로 복원하고 지원되지 않는 리디렉션 설정을 제거합니다. 각 파일은 v0.3.16 원본·공유 대상과 바이트가 완전히 같으며 사진을 다시 인코딩하지 않았습니다. 현재 갤러리 경로와 외관별 원본 출처 링크는 유지합니다.

10월 31일 콘텐츠 갱신과 방문자 데이터 용량 감소를 모두 유지합니다. 표준 형식 후보 tar는 헤더를 포함해 압축 해제 시 267,943,936바이트이며, 256 MiB 제한 아래 491,520바이트의 여유가 있습니다. 다음 갱신도 배포 용량 검사를 통과해야 합니다. 패키지·잠금 파일 버전은 일치하며 v0.3.16·v0.3.17 태그는 보존합니다.

타입, 테스트 50개, 콘텐츠·사진·출처 검사, 예상 이력 불변, 루트 Worker 빌드와 표준 압축 파일 사전 검사를 통과했습니다. 독립 검토에서 복원한 모든 사진을 과거 원본·현재 공유 대상과 비교했습니다. 방문자 모듈과 표시 데이터가 같으므로 v0.3.17 한영 브라우저 검사도 그대로 적용됩니다. 배포 후 실제 호스팅과 이전 주소 네 개의 응답을 직접 확인해야 하며, 로컬 리디렉션 동작만으로는 충분하지 않았습니다. 기존 브라우저·성능·권리 확인 한계는 남습니다.
