# 0.3.11 — 장신구 5종 갤러리·과거 상점 조건 보완

[English](../../en/releases/0.3.11.md) · [사이트](https://windsahead.com/ko) · [출처 점검](../gallery-followup-2026-10-17.md) · [PR #52](https://github.com/developdh/Winds-Ahead/pull/52)

기존 쇄란로·가모해·하간의담·모충아·답비연 5종의 빈 중국 갤러리를 채웠습니다. 확인한 공식 사진 5장, 장신구 중심 미리보기와 전체 사진 확대, 한국어 임시 독음, 과거 순환 상점 조건을 보완했습니다. 공시 정가 장명주 680/60개와 미확인 실제 결제액을 명확히 구분하며 무작위 상품·할인을 확정 가격으로 표시하지 않습니다.

분 단위·시간대 미표기의 과거 이벤트 상점 종료(2026년 10월 12일 05:00) 5건을 추가했습니다. 이벤트 운영 기간이며 개별 최초 출시일이 아닙니다. 사전 공지를 다시 읽고 근거가 부족했던 중국 출시 확정 5건을 확인 중으로 바로잡았습니다. 미발표 글로벌 대응·개별 날짜는 미정입니다. 도감은 외관 734종·외관 489종의 사진 851장·빈 갤러리 245종·서버 기록 676건·글로벌 일정 231건·종료 일정 52건입니다.

획득 표는 기준 정가가 공지됐어도 실제 필요량이 미확인일 수 있으므로, ‘공지에 수량 미표기’ 대신 ‘확정 필요 수량 미확인’으로 설명합니다.

타입 검사·기존 테스트 44개·콘텐츠/미디어/출처 검증·예상 이력 보존 검사·배포용 Worker 빌드를 통과했습니다. 앱 내 Chromium에서 한국어 모바일·영문 데스크톱 상세 5종, 전체 사진 확대·원본 링크 5종, 한국어 꽃 발식 상세의 320/360/390/768/1024/1440px 화면을 확인했고 가로 넘침이 없었습니다. 수집된 브라우저 오류 로그는 없습니다. [UI 기록과 화면](../../research/2026-10-17-gallery-ui/results.json). 실기기·Firefox/WebKit·200% 확대·실험실 성능은 미검증이며 기존 빌드 설정·청크 크기 경고는 남아 있습니다.

새 파일 합계는 전체 사진 482,760바이트·본문 자르기 277,204바이트·썸네일 207,356바이트·선택용 미리보기 20,198바이트입니다. 첫 화면 전송량 측정값은 아닙니다. 사진 권한·현재 게임 내 획득 여부는 미확인이며 예상 이력·예약·매거진·사이트 공개 범위는 유지했습니다.
