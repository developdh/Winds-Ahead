# 연운경 v0.3.2

[English](../../en/releases/0.3.2.md) · [창간호](https://windsahead.com/ko/magazine/issue-01)

웹 기사와 모바일판을 정보 중심 문구로 정리했습니다. 편집자의 편지·외관 감상·홍보 문구·참여 유도 문장을 제거하고 제목을 **10월 외관 업데이트**로 바꿨습니다. 현재 모바일 다운로드는 표지·공식 출시 예고 네 가지·기존 예상 후보의 여섯 장으로 줄였습니다. 사진 중심 패션 매거진 디자인은 유지하고 외관명·일정·가격·획득처·지원 기능을 항목별로 표시합니다. 홍염의 밤 개별 지면에는 여성 참고사진 전체를 담습니다.

수정판 3은 정보 기준일·공식 사실·미확인 종료 시간대·기존 연대학 예상 3차 기록을 유지합니다. 이전 수정판 다운로드 경로는 보존합니다. 중국 공식 참고사진은 출처와 미확인 재배포 허가 상태를 유지합니다. 예상·정기 작업을 추가하지 않습니다.

타입, 기존 테스트 46개, 콘텐츠·내보내기·예상 이력 검증과 루트 빌드를 통과했습니다. Chrome 한국어 320/390px·영어 360/1440px에서 미리보기 여섯 장, ZIP, 회차 이동, 언어 전환, 도감 링크, 출처, 양언어 메타데이터·사이트맵과 미존재 회차 404를 확인했고 가로 넘침·깨진 로드 이미지·페이지 오류가 없었습니다. 두 언어 화보를 시각 검토했습니다. 기존 프레임워크·큰 청크 경고는 남아 있으며 실제 기기·커뮤니티 업로드 압축·실사용 성능은 검증하지 않았습니다.
