# Winds Ahead v0.2.10

[English](../../en/releases/0.2.10.md) · [성월륜](https://windsahead.com/ko/cosmetics/global-moonhare-merriment)

성월륜에 [貓植事x恩奇ANCHI 글로벌 외관 도감](https://acp.idv.tw/where_winds_meet/moonhare-merriment/)에서 확인한 사진 2장을 추가했습니다. 여성 착용 후면 사진과 아이템 설명 화면이며 전체 구도와 워터마크를 유지합니다. 갤러리에 실제 제공처를 표시하고 최적화한 전체 사진 2장의 용량은 합계 42,390바이트입니다.

커뮤니티 참고 정보 영역에 등 중앙 착용, 남녀 공용, 위치·크기 조절, 풍화치 30을 안내합니다. 풍화치는 수집 점수이며 가격이 아님을 명시했습니다. 한국어 공식명과 이벤트 획득 조건은 [한국 공식 카페 공지](https://cafe.naver.com/wherewindsmeet/2270)를 근거로 유지합니다. 정확한 이벤트 시각·시간대·별도 중국 서버 항목과의 대응은 미확인 상태입니다. 이미지 재사용 허가는 미명시이며 출처 표기를 허가로 간주하지 않습니다.

앞으로 이름·획득처·종료 일정·빈 사진을 함께 점검하고 확인된 누락을 개별 요청 없이 보완한다는 운영자 지시를 양국어 프로젝트 지침과 기존 점검 절차에 저장했습니다. 예약은 추가하지 않았습니다.

검증: 타입 검사, 테스트 46개, 콘텐츠 검사, 예상 이력 보존 검사, 배포용 빌드를 통과했습니다. Chromium에서 390px 한국어 화면, 두 사진 전환·확대·닫기, 사진 출처 표시, 1440px 영어 화면을 확인했으며 가로 넘침은 없었습니다. 실제 기기와 Firefox/WebKit은 테스트하지 않았고 기존 빌드 경고는 남아 있습니다.
