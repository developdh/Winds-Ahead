# 0.3.21 — Willow Breeze와 Heaven-Sent Verse 외관 대응 정정

[English](../../en/releases/0.3.21.md) · [웹사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-11-08.md) · [이전 릴리스](0.3.20.md)

같은 글로벌 외관으로 잘못 연결됐던 두 의상을 분리했습니다. 青玉案은 Willow Breeze, 贺新词는 Heaven-Sent Verse입니다. 영어명이 표시된 글로벌 사진과 2026년 3월 6일 상점 예고를 Heaven-Sent Verse로 옮겼습니다. 기존 외관 식별자와 이미지 URL은 유지하고 이전 기록은 날짜별 감사 자료에 보존했습니다.

Willow Breeze 여성 참고 사진과 공식 복각 기간을 추가했습니다. 2026년 11월 13일 23:00부터 2027년 1월 29일 04:59:59까지이며 시간대는 UTC+8입니다. 복각 종료는 Frostbound Edge 강호령 종료와 구분합니다. 가격이 공개되지 않은 강호령 복각 외관의 획득 방식은 재화 교환으로 단정하지 않고 ‘획득 요건 미표기’로 표시합니다. 글로벌 최초 출시일, 복각 가격과 구체적인 교환 경로는 미정입니다.

중국 贺新词 공식 예고와 2025년 5월 16일의 과거 상점 조건인 장명주 300개·정가 680개를 추가했습니다. 중국 가격에만 해당합니다. 사전 예고만 있는 과거 기록은 예고 상태로 두고 실제 출시 확인 대기로 표시합니다. 한국어 공식명은 미확인이며 이전 출시 예상 이력은 변경하지 않았습니다.

외관 764개, 518개 갤러리의 이미지 919개, 서버별 기록 730개, 글로벌 일정 258개, 종료 일정 88개를 포함합니다. 새 사진은 WebP 파생 파일 네 개로 제공하며 여성 인물 중심 미리보기와 확대 시 전체 포스터를 보존합니다.

TypeScript, 테스트 52개, 콘텐츠·미디어 검증, 프로덕션 의존성 보안 검사와 저장소 루트 Worker 빌드를 통과했습니다. 배포 아카이브의 압축 해제 크기는 268,335,104바이트로 256 MiB 한도보다 100,352바이트 작습니다. 로컬 Chromium에서 두 외관의 영어 데스크톱·한국어 모바일 화면, 갤러리 확대·원본 링크, 별도 복각 종료, 획득 문구와 양언어 로드맵을 확인했고 가로 넘침은 관찰되지 않았습니다. 실제 기기·다른 브라우저·200% 텍스트·느린 네트워크·게임 내 판매 상태는 검증하지 않았습니다. 배포 여유가 매우 작으므로 다음 사진 업데이트 전에 용량을 확인해야 합니다.
