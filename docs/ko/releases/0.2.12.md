# Winds Ahead v0.2.12

[English](../../en/releases/0.2.12.md) · [웹사이트](https://windsahead.com/ko) · [PR #37](https://github.com/developdh/Winds-Ahead/pull/37)

9월 29일 [영어](https://www.wherewindsmeetgame.com/news/official/929update.html)·[한국어](https://www.wherewindsmeetgame.com/kr/news/official/929update.html) 이미지 공지에서 10월 4일 글로벌 출시 예정 외관 3종을 추가했습니다. **홍염의 밤**은 장명주 1,280개, **광명의 길**은 680개, **불꽃 축제의 밤**은 할인가 60개·정가 300개입니다. 원본 이미지를 대조해 기존 중국 기록에 연결했으며 중복 항목은 만들지 않았습니다.

**어룡의 불꽃**의 글로벌 공명 상점 비용은 **공명 구슬 1개**로 확인했습니다. 불꽃 축제의 밤의 **11월 3일 할인 종료**는 판매 종료와 구분합니다. 새 이미지 공지는 시간대를 명시하지 않아 영문 05:00·한국어 06:00 표기를 그대로 안내합니다. 어룡의 불꽃에 이미 확인된 UTC+8을 다른 외관에 임의 적용하지 않았습니다. 모두 출시 예고 상태입니다.

홍염의 밤 공식 여성 사진과 [서운 장식 여성 착용 사진](https://acp.idv.tw/where_winds_meet/cloudgrace-earrings/)을 추가하고 전체 구도·워터마크를 유지했습니다. 불꽃 축제의 밤의 어두운 정지 사진은 불꽃이 보이는 영상 6초 장면으로 교체했습니다. 서운 장식의 커뮤니티 외형 정보는 공식 획득 조건·미확인 중국 항목 대응과 구분합니다. 재배포 허가는 여전히 미확인입니다.

기존 링크가 열리지 않는 중국 수정 공지는 [현재 누적 공지](https://www.yysls.cn/news/update/20260929/40412_1315311.html)를 이미 검증된 외관 4종의 보강 출처로 추가했습니다. 초기 비공개 시제품 상태로 남아 있던 영어·한국어 MVP 현황 문서도 현재 운영 상태에 맞췄습니다. 기존 예상·수정 이력·예약은 유지했습니다.

[출처 확인·원문 불일치·수집 제한 기록](../../research/2026-09-29-september30-update.json)

타입 검사, 도메인·미디어 테스트 46개, 콘텐츠 검증, 예상 이력 보존, 프로덕션 Worker 빌드를 통과했습니다. Chromium에서 390px 한국어 로드맵·홍염의 밤 여성 우선 갤러리와 다음 사진 이동, 서운 장식 사진·커뮤니티 출처, 1440px 영문 불꽃 축제의 밤 상세와 할인 종료 구분을 확인했습니다. 해당 화면에서 깨진 로드 이미지·가로 넘침·브라우저 오류는 관찰되지 않았습니다. 라이선스를 보존한 두 글꼴 서브셋을 갱신하고 새 한국어 글자 수록도 확인했습니다. 기존 대용량 청크·프레임워크 경고는 남아 있으며 실제 기기·Firefox·WebKit·실사용 성능은 미검증입니다.
