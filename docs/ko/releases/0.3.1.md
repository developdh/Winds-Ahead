# 연운경 v0.3.1

[English](../../en/releases/0.3.1.md) · [창간호](https://windsahead.com/ko/magazine/issue-01) · [PR #42](https://github.com/developdh/Winds-Ahead/pull/42)

공유판을 언어별 사진 중심 패션 화보 여덟 장으로 다시 편집했습니다. 여성 외관 사진이 꽉 찬 표지, 큰 명조 제목, 크림·남색·세이지 지면, 디테일 확대와 연대학 여성 정면·후면 화보로 현재 다운로드를 교체합니다. 공식 10월 4일 출시 예고 외관마다 개별 사진 지면이 있어 링크 없이 모두 볼 수 있습니다. 정보 기준일과 기존 예상 3차 기록은 유지하며 수정판 2에 시각 편집 변경을 기록합니다.

웹사이트에서 가로 1080px JPG와 ZIP을 제공합니다. 이미지 공간을 예약한 작은 WebP 미리보기를 지연 로드합니다. 내보내기 메타데이터를 public 대신 content에서 읽어 Vite 개발 중 가져오기 오류를 해결했습니다. 최초 수정판 PNG·ZIP·메타데이터는 과거 경로에 보존합니다. 공유 문안까지 글꼴 서브셋에 포함하고 OFL 고지를 유지합니다.

사용자가 요청한 기존 중국 공식 사진을 공유판에 넣습니다. 원본 경로·URL·미확인 허가 상태를 기록하고 전체 원본은 도감에서 볼 수 있습니다. 글로벌 실착 확인 사진이 아니며 출처 표기가 재배포 허가를 뜻하지 않습니다. 공식 예고·운영자 예상·미확인 종료 시간대는 구분합니다. 예상·정기 작업·커뮤니티 게시를 추가하지 않습니다.

Windows에서 타입, 기존 테스트 46개, 콘텐츠·내보내기, 예상 이력 보존 검증과 루트 배포 빌드를 통과했습니다. Chrome 한국어 320/390px·영어 360/1440px에서 가로 넘침·깨진 로드 이미지·페이지 오류가 없었습니다. 미리보기 여덟 장, ZIP, 회차 이동, 언어 전환, 도감 링크, 출처, 양언어 메타데이터·사이트맵과 미존재 회차 404를 확인했습니다. JPG·WebP 총 16쌍의 크기·용량을 검증했으며 JPG 약 350~480KB, 미리보기 약 29~42KB입니다. 두 언어 화보를 시각 검토했습니다. 기존 프레임워크·큰 청크 경고는 남아 있으며 실제 기기·커뮤니티 업로드 압축·실사용 성능은 검증하지 않았습니다.
