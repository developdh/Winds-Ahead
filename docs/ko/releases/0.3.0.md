# 연운경 v0.3.0

[English](../../en/releases/0.3.0.md) · [매거진](https://windsahead.com/ko/magazine) · [PR #41](https://github.com/developdh/Winds-Ahead/pull/41)

세 번째 주 메뉴로 매거진을 추가하고 양언어 회차 목록·고정된 회차 페이지를 만들었습니다. 창간호 **다음 옷장을 미리 펼치다**는 홍염의 밤·글로벌 10월 4일 공식 외관 네 가지·기존 연대학 예상 3차 기록·할인 종료 해석·독자 제안을 다룹니다. 공식 일정·근거 제한적 예상·중국 참고사진·종료 시간대 미확인을 명시합니다. 새 예상·정기 예약·커뮤니티 자동 게시를 추가하지 않았습니다.

웹판에는 읽기 쉬운 본문·목차·전체 참고사진·도감 및 로드맵 링크가 있습니다. 모바일 커뮤니티판은 언어별 가로 1080px PNG 여섯 장이며 개별 다운로드와 ZIP 묶음을 제공합니다. 다운로드에는 자체 문안·그래픽만 담으며 재배포 허가가 미확인인 게임 사진은 제외합니다. 양언어 메타데이터·사이트맵·콘텐츠 검증을 추가하고 라이선스를 유지한 글꼴 서브셋을 갱신했습니다.

Windows에서 타입·기존 테스트 46개·양언어 콘텐츠와 공유 파일 검증·저장소 루트 배포 빌드를 통과했습니다. 기존 프레임워크·큰 청크 경고는 유지됩니다. 실제 기기·Firefox/WebKit·커뮤니티 업로드 압축·실사용 성능은 검증하지 않았습니다.
