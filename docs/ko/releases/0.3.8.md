# 0.3.8 — 10월 15일 글로벌 외관 예고·공식 시간대 보완

[English](../../en/releases/0.3.8.md) · [사이트](https://windsahead.com/ko) · [출처 점검](../content-review-2026-10-13.md) · [PR #49](https://github.com/developdh/Winds-Ahead/pull/49)

공식 글로벌 X 원문·사진·영상을 직접 확인해 Scarlet Whispers, Veil of Lotus, Crane Ascending: Chordsong을 기존 중국 항목 세 개에 연결했습니다. 10월 15일 예고와 11월 14일 강호령·12월 28일 공명 세트 종료 04:59:59 UTC+8을 추가했습니다. 시작 시각·미표기 글로벌 비용·한국어 공식명은 미확인입니다. 중국 비용·혜택과 구분하며 예고 상태를 유지합니다.

10월 9일 영어·한국어 외관 본문으로 기존 10월 11일 예고 다섯 건에 05:00 UTC+8을 보완하고 설산의 매화의 2027년 1월 9일 교환 종료 및 비휴의 축복의 11월 23일 할인 종료 시간대 UTC+8을 확인했습니다. 한국어 현지 시각은 시간대를 추정하지 않고 별도로 보존하며 비휴의 할인 종료를 판매 종료로 바꾸지 않았습니다.

글로벌 공식 참고 사진 14장과 여성 중심 미리보기를 추가하고 확대에서 전체 원본 구도를 유지했습니다. 외관 723개, 외관 473개에 사진 813장, 서버별 기록 655개, 글로벌 일정 219개, 종료 일정 35개입니다. 미확인 미디어 재배포 허가를 기록합니다. 영상·예상·정기 작업·매거진 수정판을 추가하지 않았습니다.

검증: 타입 검사·도메인 및 미디어 테스트 44개·콘텐츠 검증·예상 이력 보존·루트 프로덕션 Worker 빌드가 통과했습니다. 프로덕션 의존성 검사에서 알려진 취약점이 없었습니다. 앱 내 Chromium에서 영어 1440px·한국어 390px의 변경 관련 상세 여덟 개씩, 기본 사진 로딩·서버별 조건·미확인 표기를 확인했으며 가로 넘침이 없었습니다. 한국어 로드맵·캘린더에서 10월 15일 세 건을 확인했고 320px에서도 페이지 가로 넘침이 없었습니다. Scarlet Whispers 확대에서 전체 포스터가 로드되었습니다. 브라우저 경고·오류가 기록되지 않았습니다. [UI 근거](../../research/2026-10-13-ui/results.json).

추가 썸네일 14장은 총 856,762바이트, 전체 파생본 2,670,746바이트, 선택용 사진 54,014바이트, 표시용 크롭 338,380바이트입니다. 자산 합계이며 첫 화면 전송량 측정치는 아닙니다. Sites 빌드 도우미 첫 실행은 Windows npm 경로를 찾지 못했지만 기존 루트 npm 빌드가 정상 완료되었습니다. 기존 프레임워크·청크 경고가 남습니다. 게임 내 실제 획득 가능 여부·X 전체 이력·한국 공식 카페 최신 글·실기기·Firefox/WebKit·200% 텍스트 확대·실사용 성능은 미검증입니다. 사이트 공개 범위와 매거진은 유지했습니다.
