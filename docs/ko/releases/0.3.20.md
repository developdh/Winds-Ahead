# 0.3.20 — 중국 11월 외관과 글로벌 1주년 예고

[English](../../en/releases/0.3.20.md) · [사이트](https://windsahead.com/ko) · [출처 검토](../content-review-2026-11-07.md) · [이전 릴리스](0.3.19.md)

11월 6일 중국 업데이트에서 강호령 의상, 상점 의상·우산, 공명 상점 헤어·탈것, 보상 장신구 4종 등 외관 9종을 추가했습니다. 패치에 명시된 강호령·의상·헤어 종료 시각과 변경된 거북이 이벤트 운영 기간을 반영했습니다. 중국 공지의 시간대와 장신구의 별도 수령 기한은 미정입니다. 수정 공지는 11월 6일까지 空林蜕梦이 게임에 등장했음을 뒷받침하며 실제 최초 판매 시각은 미정입니다.

공식 이미지를 대조해 기존 중국 외관 5종에 글로벌 영어 공식명과 11월 13일 1주년 예고를 연결했습니다. 강호령·이벤트·뽑기 기간은 UTC+8로 기록했습니다. 한국어 공식명, 미공개 가격, 개별 보상 수령 기한은 미확인입니다. Willow Breeze는 도감 연결을 확정할 때까지 검토 기록에 보관합니다.

Windows에서도 방문자용 데이터 변환 테스트가 실행되도록 테스트 파일 URL을 운영체제의 파일 경로로 변환했습니다.

검수한 참고 이미지 13장과 WebP 파생 이미지 52개를 추가했습니다. 갤러리 선택기는 본문 미리보기와 같은 영역을 사용하고, 확대하면 선택한 이미지 전체를 볼 수 있습니다. 도감은 외관 764종, 갤러리 517개의 참고 이미지 918장, 서버별 기록 728건, 글로벌 일정 257건, 종료 일정 87건입니다. 새 한국어 공지는 공식 네이버 라운지에서 확인합니다.

TypeScript, 테스트 52개, 콘텐츠·미디어 검증, 이전 예상 이력 검증, 배포용 의존성 보안 검사를 통과했습니다. 로컬 Chromium에서 한국어 모바일 의상 상세·원본 확대와 11월 13일 예고 5건이 표시되는 로드맵, 영어 데스크톱 Frostbound Edge 상세를 확인했습니다. 실기기, 다른 브라우저, 게임 내 획득 가능 여부는 확인 범위에 포함하지 않았습니다.
