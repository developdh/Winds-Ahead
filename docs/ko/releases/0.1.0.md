# Winds Ahead v0.1.0

[English](../../en/releases/0.1.0.md) · [웹사이트](https://windsahead.com) · [GitHub 릴리스](https://github.com/developdh/Winds-Ahead/releases/tag/v0.1.0)

연운 외관 도감과 출시 로드맵을 제공하는 독립 팬 프로젝트 **Winds Ahead / 연운경(燕雲鏡)**의 첫 공개 릴리스입니다.

## 포함된 기능

- 영어·한국어 지원, 언어 선택 저장, PC·모바일에 대응하는 어두운 화면 구성.
- 외관 기록 685개, 외관 370종의 사진 554장, 위키 참고 항목 395개. 이름·별칭 검색, 종류·서버 필터와 서버별 출시일 정렬.
- 큰 사진과 좌우 넘기기를 갖춘 상세 팝업. 획득처·필요 재화·가격·의상 구성 확인, 개별 외관 공유와 브라우저에 저장되는 관심 목록.
- 중국·글로벌 출시 상태, 공식 출시 예정과 비공식 AI 기반 예상을 구분한 로드맵·월별 캘린더.
- 필요한 사진부터 불러오고 재생을 누를 때 영상을 불러오는 방식. 이펙트 영상 전체를 자동 재생하지 않습니다.
- 로그인 없이 공개 이용, 기여 안내, 한영 문서와 오픈소스 앱 코드.

## 함께 반영한 최근 수정

의상 사진과 글로벌 공식 소셜 출처를 보강하고 Bane of Life 헤어·장신구 세트를 반영했습니다. 예정 기간이 지났지만 출시 여부가 확인되지 않은 공지는 앞으로의 로드맵에서 숨깁니다. 원본 기록과 캘린더 이력은 보존합니다. [사진·소셜 정보 갱신](https://github.com/developdh/Winds-Ahead/pull/20), [로드맵 수정](https://github.com/developdh/Winds-Ahead/pull/23)을 참고하세요.

## 검증과 남은 범위

앱 변경의 타입 검사, 도메인·미디어 테스트 32개, 콘텐츠 검증과 운영 빌드를 통과했습니다. 한영 로드맵을 확인했으며 로그인하지 않은 운영 사이트 요청은 HTTP 200을 반환했습니다. 자세한 검증 범위는 [공개 검토](../public-launch.md), [로드맵 검토](../release-roadmap.md)에 기록했습니다.

도감은 계속 보강 중입니다. 315개 기록에는 검토된 사진이 없으며 일부 이름·가격·출시일은 미정입니다. 예상은 비공식이며 바뀔 수 있고 실제 출시 확인을 의미하지 않습니다. 실물 기기별 검증과 실제 이용 환경의 성능 목표 달성은 아직 확인되지 않았습니다.

직접 작성한 코드와 프로젝트 문서는 MIT 라이선스를 적용합니다. 게임 미디어·위키 가공 자료 등은 별도 권리를 유지하며 [외부 저작물 안내](https://github.com/developdh/Winds-Ahead/blob/v0.1.0/THIRD_PARTY_NOTICES.md)를 따릅니다. 수익을 창출하지 않는 독립 팬 프로젝트입니다.
