# 0.2.6 — 여성 우선 미리보기와 예상 목록 동기화

[English](../../en/releases/0.2.6.md) · [웹사이트](https://windsahead.com/ko/calendar) · [이미지 보정 기록](../../research/2026-09-23-preview-framing.json) · [PR #31](https://github.com/developdh/Winds-Ahead/pull/31)

떠오르는 달빛·황금빛 설렘에서 빠진 그림 하단 테두리를 복원했습니다. 포스터 132개에는 카드·상세·빠른 보기·사진 선택용 인물 또는 외관 중심 구도를 별도로 만들고, 전체 이미지는 전체 맞춤·확대 갤러리에서 유지합니다. 사용자 요청인 여성 우선 미리보기 규칙을 프로젝트 지침과 한영 디자인 문서에 추가했습니다. 확인한 여성 구도 68개를 먼저 선택하며 원래 출처 인덱스와 다른 사진도 유지합니다.

캘린더 아래 예상 기간과 로드맵이 같은 유효 예상 선택 기준·순서·기간 표시를 사용합니다. 선택한 달 이후의 기간을 포함해 현재 예상 5개가 모두 표시됩니다. 월 이동은 공식 날짜 기록에 적용하고, 확정 일정·중국 서버 필터에서는 예상을 제외합니다. 철회·기간 종료·공식 정보 우선·변경 이력의 의미는 유지합니다.

검증: 타입 검사, 도메인·미디어 테스트 41개, 콘텐츠 검사와 프로덕션 Worker 빌드를 통과했습니다. 앱 내 Chromium에서 한국어 전체 이미지 맞춤을 320/360/390/768/1024/1440 CSS px로 확인하고, 전체 맞춤·확대·캘린더/로드맵 목록 일치·월 이동·일정/서버 필터를 확인했습니다. 해당 너비의 캘린더에 가로 넘침이 없으며 영어 모바일 표시와 목록 유지도 확인했습니다. 포스터 구도는 비교 이미지로 시각 검토했습니다. 표시용 132개 파일 합계는 약 4.67MB이며 필요한 곳에서 로드하고, 작은 선택 이미지 582개의 합계는 약 1.66MB입니다. 기존 Vite 설정·번들 크기 경고는 남아 있습니다. 실물 기기·Firefox/WebKit·느린 네트워크·실사용 성능은 측정하지 않았습니다.
