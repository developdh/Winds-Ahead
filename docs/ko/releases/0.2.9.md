# Winds Ahead v0.2.9

[English](../../en/releases/0.2.9.md) · [사이트](https://windsahead.com)

Moonhare Merriment의 임시 음역을 한국어 공식명 **성월륜**으로 정정했습니다. [GM 연지의 9월 27일 한국 공식 카페 공지](https://cafe.naver.com/wherewindsmeet/2270)에서 이벤트명 **달빛 동행**도 확인했습니다. 상세 화면·검색 결과·종료 임박 목록에 정정된 이름을 표시하고 이벤트·종료 기록에 한국어 근거를 연결했습니다. 이전 음역은 검색어로만 남겼습니다.

영문명·항목 ID·이벤트 날짜·미명시 시간대·중국 항목 대응 미확인 상태는 유지합니다. 과거 릴리스 기록도 보존합니다. 기존 콘텐츠 점검 절차에 한국 공식 카페의 명칭 확인을 명시했으며 예약은 추가하지 않았습니다.

검증: 타입 검사·테스트 44개·콘텐츠 검증·운영 빌드가 통과했습니다. Chromium에서 한국어 상세·종료 임박 목록 390px, 영어 상세 1440px, 공식 출처 링크와 이전 이름 검색을 확인했습니다. 가로 넘침은 없었습니다. 실제 모바일 기기·Firefox/WebKit은 미검증이며 기존 빌드 경고는 남아 있습니다.
