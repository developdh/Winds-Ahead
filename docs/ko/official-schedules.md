# 공식 일정과 예상 중단 정책

[English](../en/official-schedules.md)

2026년 10월 2일(America/New_York) 사용자는 혼란을 줄이기 위해 운영자 출시 예상을 중단했습니다. 이 결정은 프로젝트 전반의 이전 예상 관련 요구와 제안보다 우선합니다.

도감·로드맵·캘린더·사이트 소개·매거진에는 공식 일정과 서버별로 확인된 출시 기록을 사용합니다. 글로벌 공식 발표가 없으면 날짜를 미정으로 유지합니다. 예고 날짜가 지났다고 실제 출시로 자동 전환하지 않으며 중국 서버 사실만으로 글로벌 출시일을 확정하지 않습니다.

점검에서 향후 출시 예상을 생성·수정·재활성화·게시·재검토하지 않습니다. 기존 절차로 공식 명칭·획득처·가격·종료 일정·사용 가능한 누락 사진을 계속 확인합니다. 대체 정기 예약이나 자동 병합을 추가하지 않습니다.

기존 예상 8개 계열의 마지막에 명시적인 철회 기록을 추가했습니다. 이전 기록은 `site/content/forecasts.json`에 감사용으로만 보존하고 방문자 앱에서 불러오지 않습니다. 과거 조사와 릴리스 문서는 당시 작업 기록이며 현재 제품 요구가 아닙니다.

매거진 창간호 수정판 5에서는 예상 기사와 표지 언급을 제거했습니다. 공유판 6장은 표지·공식 출시 예고 외관 네 가지·사이트 소개로 구성합니다. 이전 공유판 파일은 공개 자산에서 제거하고 Git 이력에서 복원 가능하게 보존하므로 이전 다운로드 주소는 더 이상 제공하지 않습니다. 이미 다운로드한 파일은 회수할 수 없습니다.

검증·게시에는 [릴리스 절차](releasing.md)를 따릅니다. 이번 변경은 운영 정책과 화면의 예상 제거이며 새로운 출처 확인이나 이전 예상 정확도의 검증이 아닙니다.
