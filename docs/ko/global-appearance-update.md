8종 모두 9월 16일 업데이트 후 출시 예정입니다. 기존 글로벌 기록 2종을 보강하고 6종을 추가했습니다. 도감·팝업·로드맵에 공식명을 표시하고 기존 한국어 독음도 검색 별칭으로 남겼습니다. 중국 외관 연결은 운영자의 이미지 대조 결과이며 공식 서버 간 명칭 대응표가 아닙니다. 특히 이름의 의미가 크게 다른 Shattered Asura / 봄빛 호리병은 호리병과 피리를 단 동일한 동물 장신구 이미지로 확인했습니다.

글로벌 공지에 명시된 강호령·공명·상점·공명 상점을 기록했습니다. 무기·동물 장신구 4종의 글로벌 획득처는 이번 공지에 없어 미정입니다. 가격·통화·보상 레벨은 미정으로 유지합니다. 공명 방식이 확인됐어도 통화는 모를 수 있으므로 출처 설명이 있을 때만 통화 미정을 허용하며, 외관의 확정 가격으로 바꾸지 않습니다.

영문 공지의 종료 시각은 UTC+8을 명시합니다. 한국어 공지의 종료 표현은 시간대가 없으므로 따로 보존했습니다. 앞의 세트 4종은 시작일의 UTC 근거가 있고, 무기·동물 장신구의 시작 시간대는 미표기입니다. 실제 출시·현재 획득 가능 여부를 단정하지 않으며 기존 예상 이력은 변경하지 않았습니다.

허공의 물결 남성형 앞·뒷모습, 우산 윗면·측면, 여성형·남성형 부채 사진 총 3장을 보강했습니다. 원본 약 7.5MB를 확대용 WebP 합계 744KB, 미리보기 합계 126KB로 최적화했으며 기존 갤러리에서 필요할 때 불러옵니다. 출처 표기가 재배포 허가를 뜻하지 않으며 게임 미디어는 코드 라이선스에서 제외합니다.
