# 상세 이미지 갤러리 · 2026년 9월 13일

[English](../en/gallery-navigation.md)

상세 이미지를 열면 선택한 외형이 유지되며 사진 위의 큰 이전·다음 꺾쇠 버튼, 가로 드래그·스와이프, 좌우 방향키로 이동할 수 있습니다. 아래에는 사진 번호와 해당 사진의 공식 원본 링크를 표시합니다. 사진이 한 장이면 이동 버튼을 생략하고, 첫 장과 마지막 장에서는 이동할 수 없는 방향을 비활성화합니다. 닫으면 열기 버튼으로 초점이 돌아오며 상세 썸네일도 갤러리에서 선택한 사진을 따릅니다.

## 움직임 수정

사용자는 애니메이션이 과한 것이 아니라 팝업 크기와 움직임이 맞지 않는 문제를 지적했습니다. 브라우저에서 기본 팝업의 `transition-property: all`, `0.2s` 크기 전환과 별도의 `0.65s` 등장 애니메이션이 함께 적용되는 것을 확인했습니다. 화면 폭을 빠르게 바꾸면 지정된 팝업 폭 대신 중간 크기가 나타났습니다.

갤러리의 레이아웃 전환을 명시적으로 끄고, 뷰어와 전체 이미지가 로드되기 전부터 높이를 확보하며, 팝업 전체에 하나의 등장 효과를 적용합니다. 사진 자체의 별도 등장 변형과 움직이는 흐림 효과는 제거했습니다. 사진의 좌우 이동은 고정된 표시 영역 안에서 이루어집니다. 짧은 사진은 가운데 정렬하고 긴 홍보 이미지는 세로로 스크롤할 수 있습니다. 움직임 줄이기 설정에서는 등장 효과를 끄고 사진 이동 시간도 0으로 처리합니다. 공용 UI 원본 컴포넌트는 수정하지 않았습니다.

## 로딩과 선택 상태

갤러리 뷰어와 캐러셀은 팝업을 열 때 따로 불러옵니다. 선택한 전체 이미지를 먼저 불러오고, 준비되면 바로 이웃한 사진을 낮은 우선순위로 불러옵니다. 요청한 전체 이미지는 팝업을 닫을 때까지 유지하므로 이동 중 잘린 썸네일로 교체되지 않습니다. 미리 불러오기는 선택한 사진의 이웃을 넘어 연쇄적으로 진행되지 않습니다. 로딩·이미지 오류 안내에서도 바깥 크기는 유지합니다. 갤러리 크기를 다시 계산할 때 현재 사진을 복원하며, 다른 외관으로 이동하면 외관 ID 기준으로 상세 상태를 초기화해 사진이 한 장인 항목에 이전의 두 번째 사진 번호가 남지 않도록 했습니다. 미디어나 의존성은 추가하지 않았습니다.

사진 이동 시 확대처럼 보이던 원인은 선택이 바뀌자마자 나가는 프레임의 React 키를 바꾸고, 가로 전체 사진을 세로로 잘린 썸네일로 교체하는 동작이었습니다. 이제 키와 전체 이미지 주소를 유지해 가로 이동 중에도 각 사진의 크기가 일정합니다. 기존 팝업 등장 효과와 배경 없는 꺾쇠는 유지했습니다.

빌드된 갤러리 클라이언트 모듈은 25,337바이트이며 로컬 gzip 압축 시 10,002바이트입니다. 모듈 용량 측정으로, 페이지 전체 전송량이나 실제 사용자 성능 점수는 아닙니다.

## 검증

- 인앱 Chromium에서 한영 갤러리, 이전·다음 버튼, 끝에 도달한 뒤 방향키 이동, 모바일 폭의 가로 드래그, 두 번째 썸네일 선택 후 열기, 사진별 원본 링크, 닫기와 초점 복귀를 확인했습니다.
- 사진 이동 회귀 검증: 보추정 사진 두 장 모두 이동 중 전체 이미지 주소를 유지하며 썸네일 노드가 없습니다. 화면 폭 390px에서는 각각 348 × 195.75px, 1440px에서는 각각 998 × 561.375px를 유지했습니다(소수점 반올림 차이 0.001px 이내). 버튼·방향키·드래그 이동과 두 번째 사진으로 다시 열기를 확인했습니다.
- 화면 폭 320·360·390·768·1024·1440 CSS px에서 영역을 확인했습니다. 전환 수정 후 팝업 폭은 각각 304·344·374·736·992·1040px이며 모두 화면 안에 있었습니다. 사용자의 최종 조정에 따라 원형 배경과 테두리는 제거했습니다. 모바일 40px·데스크톱 44px 꺾쇠를 투명한 64px·72px 조작 영역에 배치하고 가독성을 위한 얇은 그림자만 남겼습니다. 닫기는 44px입니다.
- 작업 중 모바일·데스크톱 스크린샷을 확인했습니다. 화면 폭 검증이며 실기기 터치나 프레임 속도 인증은 아닙니다. 브라우저 도구에서 프레임별 표본 수집을 지원하지 않아 측정 FPS를 주장하지 않습니다.
- 타입 검사, 기존 날짜·미디어 테스트 19개, 콘텐츠 검사(외관 40종·이미지 66개), 게시용 빌드가 통과했습니다. 새 한국어 문구는 기존 로컬 글꼴 서브셋으로 표시할 수 있습니다.
- 실제 iOS·Android, Firefox·WebKit, 텍스트 200% 확대, 이미지 통신 실패 재현, 실행 중 움직임 줄이기 설정 변경은 이번에 직접 시험하지 않았습니다. 움직임 줄이기와 오류 처리는 소스로 검토했습니다.
