## 9월 23일 후속 수정: 여성 우선 미리보기

사용자 요청에 따라 외관의 특징이 잘 보이는 여성 이미지가 있으면 미리보기에 우선 사용합니다. 공통 사진 선택 규칙은 여성으로 확인해 표시한 사진을 먼저 배치하고, 확대 시에는 원래 이미지 인덱스를 유지합니다. 다른 사진도 계속 볼 수 있습니다. 파일명만으로 성별을 추측하거나 없는 여성 외형을 만들지 않습니다.

포스터 132개의 카드·상세·빠른 보기·사진 선택 미리보기를 인물 또는 외관 중심으로 잘라 사용합니다. 여성 구도 68개를 기록했습니다. 가능한 경우 남녀 합성 포스터 대신 개별 인물을 보여주고 무기·이펙트는 해당 외관을 중심으로 구성합니다. 확대 갤러리에서는 전체 그림과 전체 맞춤·확대를 유지합니다. 떠오르는 달빛·황금빛 설렘은 파일 자체에서 아래 테두리가 잘려 있어 하단을 복원하고 출처 자르기 좌표도 일치시켰습니다. [후속 보정 기록](../research/2026-09-23-preview-framing.json)을 참고하세요.

`media.json`의 `presentationCrop`은 전체 이미지 기준 좌표이며 확인된 여성 사진은 `presentationSubject: female`로 표시합니다. `node scripts/refresh-gallery-previews.mjs`로 표시용 사진·카드·작은 선택 사진을 다시 생성합니다. 공개 전 원본과 비교해 구도를 검토하고 미리보기용 자르기로 전체 이미지를 덮어쓰지 않습니다. 아래의 이전 미리보기·여백 유지 방식은 이번 후속 수정으로 대체합니다.

## 2026년 9월 23일: 전체 구도 유지와 선택적 확대

상세 페이지와 빠른 보기에서 전체 이미지를 고정된 영역 안에 맞춰 표시합니다. 갤러리는 처음에 화면의 가로·세로에 전체를 맞추고, ‘확대’하면 양방향으로 스크롤하며 볼 수 있습니다. ‘전체 맞춤’은 전체 구도로 복귀합니다. 다른 사진으로 이동하면 확대와 스크롤 위치를 초기화하고, 확대 중에는 사진 전환용 드래그를 꺼서 화면 이동과 충돌하지 않게 했습니다. 방향키·선택 사진·원본 링크·닫은 뒤 포커스 복귀를 유지합니다.

사막의 독충술의 잘린 오른쪽 테두리를 포함해 기존 공식 포스터 이미지 132개의 원본 그림 경계를 다시 확인해 보정했습니다. 전후 좌표는 [이미지 보정 기록](../research/2026-09-23-image-framing.json)에 남깁니다. 포스터 카드 사진은 여백을 두어 전체 패널을 보존하고, 사진 선택 목록에는 582개 전체 이미지의 구도를 유지한 최대 160px 미리보기를 별도로 사용합니다(전체 약 1.76MB, 사용되는 곳에서만 로드). 출처 연결·예상 일정·가격·미디어 권리 상태는 변경하지 않았습니다.

사진을 추가하거나 교체하면 `site/`에서 `node scripts/refresh-gallery-previews.mjs`를 실행한 뒤 콘텐츠 검증과 미디어 테스트를 수행합니다. 새 포스터 자르기는 원본의 그림 경계와 시각적으로 비교해야 합니다. 자동 자르기나 화면 표시 설정은 이미 사라진 원본 픽셀을 복원하지 못합니다. 도감 카드·사진 선택 미리보기·전체 이미지의 용도를 구분합니다.

아래는 9월 13일 당시 구현과 검증 기록이며, 처음부터 스크롤해서 보는 방식은 이번 변경으로 대체됐습니다.


상세 이미지를 열면 선택한 외형이 유지되며 사진 위의 큰 이전·다음 꺾쇠 버튼, 가로 드래그·스와이프, 좌우 방향키로 이동할 수 있습니다. 아래에는 사진 번호와 해당 사진의 공식 원본 링크를 표시합니다. 사진이 한 장이면 이동 버튼을 생략하고, 첫 장과 마지막 장에서는 이동할 수 없는 방향을 비활성화합니다. 닫으면 열기 버튼으로 초점이 돌아오며 상세 썸네일도 갤러리에서 선택한 사진을 따릅니다.

## 움직임 수정

사용자는 애니메이션이 과한 것이 아니라 팝업 크기와 움직임이 맞지 않는 문제를 지적했습니다. 브라우저에서 기본 팝업의 `transition-property: all`, `0.2s` 크기 전환과 별도의 `0.65s` 등장 애니메이션이 함께 적용되는 것을 확인했습니다. 화면 폭을 빠르게 바꾸면 지정된 팝업 폭 대신 중간 크기가 나타났습니다.

갤러리의 레이아웃 전환을 명시적으로 끄고, 뷰어와 전체 이미지가 로드되기 전부터 높이를 확보하며, 팝업 전체에 하나의 등장 효과를 적용합니다. 사진 자체의 별도 등장 변형과 움직이는 흐림 효과는 제거했습니다. 사진의 좌우 이동은 고정된 표시 영역 안에서 이루어집니다. 짧은 사진은 가운데 정렬하고 긴 홍보 이미지는 세로로 스크롤할 수 있습니다. 움직임 줄이기 설정에서는 등장 효과를 끄고 사진 이동 시간도 0으로 처리합니다. 공용 UI 원본 컴포넌트는 수정하지 않았습니다.

## 로딩과 선택 상태

갤러리 뷰어와 캐러셀은 팝업을 열 때 따로 불러옵니다. 선택한 전체 이미지를 먼저 불러오고, 준비되면 바로 이웃한 사진을 낮은 우선순위로 불러옵니다. 요청한 전체 이미지는 팝업을 닫을 때까지 유지하므로 이동 중 잘린 썸네일로 교체되지 않습니다. 미리 불러오기는 선택한 사진의 이웃을 넘어 연쇄적으로 진행되지 않습니다. 로딩·이미지 오류 안내에서도 바깥 크기는 유지합니다. 갤러리 크기를 다시 계산할 때 현재 사진을 복원하며, 다른 외관으로 이동하면 외관 ID 기준으로 상세 상태를 초기화해 사진이 한 장인 항목에 이전의 두 번째 사진 번호가 남지 않도록 했습니다. 미디어나 의존성은 추가하지 않았습니다.

사진 이동 시 확대처럼 보이던 원인은 선택이 바뀌자마자 나가는 프레임의 React 키를 바꾸고, 가로 전체 사진을 세로로 잘린 썸네일로 교체하는 동작이었습니다. 이제 키와 전체 이미지 주소를 유지해 가로 이동 중에도 각 사진의 크기가 일정합니다. 기존 팝업 등장 효과와 배경 없는 꺾쇠는 유지했습니다.

빌드된 갤러리 클라이언트 모듈은 25,337바이트이며 로컬 gzip 압축 시 10,002바이트입니다. 모듈 용량 측정으로, 페이지 전체 전송량이나 실제 사용자 성능 점수는 아닙니다.
