# 10월 7일 공식 외관 점검

[English](../en/content-review-2026-10-07.md) · [근거 기록](../research/2026-10-07-official-review.json)

10월 6일 게시된 [영어 미리보기](https://www.wherewindsmeetgame.com/news/official/1011update.html)와 [한국어 미리보기](https://www.wherewindsmeetgame.com/kr/news/official/1011update.html)는 외관 5종의 10월 11일 출시를 예고합니다. 양언어 원본 포스터의 명칭별 다섯 문단을 읽고 기존 중국 항목과 대조했으며 중복 도감 항목은 만들지 않았습니다.

| --- | --- | --- |
| 藏音·霓裳天风 | Silent Voice: Aerial Grace / 숨겨진 선율-천상의 바람 | 공명 구슬 1개; 360일 한정, 정확한 종료 시각 미표기 |

출시 시각은 10월 11일 **영어 05:00:00 / 한국어 06:00:00**이며 양쪽 모두 시간대는 미표기입니다. UTC+8·한국 시간으로 추정하지 않고 캘린더 날짜와 원문별 시각을 보존합니다. 헤어 종료는 1월 9일 **영어 04:59:59 / 한국어 05:59:59**, 이펙트 할인 종료는 11월 23일 **영어 04:59:59 / 한국어 05:59:59**입니다. 구조화된 종료 기록은 영문 현지 시각·초 단위·시간대 미확인을 유지하고 양언어 설명에 한국어 시각도 남겼습니다. 할인 종료를 판매 종료로 취급하지 않습니다. 한국어 포스터 상단에는 9월 16일이 남아 있지만 기사 제목과 개별 외관은 모두 10월 11일을 명시합니다. 헤어는 제목과 교환 문장의 설산의 매화를 사용하며 프로필 문장의 오기를 별도 이름으로 등록하지 않았습니다.

천상의 바람·매화 끝의 봄·나그네의 옷에 직접 대조한 중국 공식 여성 참고사진 3장을 추가했습니다. 헤어 미리보기는 여성 뒷모습을 중심으로 바꾸고 확대에서는 원본 포스터 전체를 유지했습니다. 비휴의 축복에 잘못 연결됐던 사자 모자 사진은 해당 글로벌 이펙트 사진으로 교체했습니다. 이전 사진은 다른 보상 문단의 이미지였으며 기존 연결 근거는 조사 기록과 Git 이력에 보존했습니다. 원본 출처 링크와 재배포 권한 미확인을 유지하고 중국 사진에는 중국 서버 표시를 남겼습니다.

중국·영어·한국어 공식 소식 목록을 확인했습니다. 중국 최신 목록은 기존 10월 3일 풍경 배경화면 글이며 10월 10·14·16일에 다가오는 기존 종료 기록을 변경할 새 공지는 확인하지 못했습니다. 한국 공식 카페는 로봇 접근 제한으로 읽지 못했습니다. 공식 SNS와 게임 내 실제 획득 여부는 별도로 확인하지 않았습니다. 글로벌 5종은 모두 출시 예고이며 날짜가 지난 기존 예고도 자동으로 출시 확인으로 바꾸지 않았습니다. 예상 이력·정기 예약·매거진 판본은 변경하지 않았습니다.

도감 총계: 외관 720종, 469종의 사진 790장, 서버별 기록 648개, 글로벌 일정 216개, 구조화된 종료 일정 29개입니다. 사진이 없는 251종은 미확인 상태로 남겼습니다.

화면 검증 중 공식 날짜가 “날짜 미정”으로 표시되는 기존 인자 오류도 수정했습니다. 테스트를 실제 호출 방식과 맞췄으며 예상 기능은 복원하지 않았습니다.
