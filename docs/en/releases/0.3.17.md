# 0.3.17 — Smaller deployment without changing artwork

[한국어](../../ko/releases/0.3.17.md) · [Website](https://windsahead.com/en) · [Content update](0.3.16.md) · [Size evidence](../../research/2026-10-31-deployment-budget.json)

The v0.3.16 content update exceeded Sites’ expanded-archive limit. This patch retains all eleven Global and three CN appearances, nineteen new references and corrected pass deadline while reducing the deployment bundle without re-encoding any image.

Four pairs of byte-identical full images now share files, saving 708,038 bytes; previous URLs return permanent redirects. Each gallery keeps its own cosmetic, source index, caption, preview crop and original-source link. Complete research and rights/inspection records remain in Git. Build-only visitor data omits unused audit fields and stores repeated text once in JavaScript, preserving every displayed value, source disclosure, acquisition excerpt and video. The client catalog chunk shrinks from 2,464,690 to 1,396,468 bytes; this is a raw build-size comparison, not a measured page-load result.

The portable candidate archive expands to 267,233,280 bytes including tar headers, down from 271,076,864, leaving 1,202,176 bytes below 256 MiB. A new archive preflight and CI step count the entire expanded tar before publication. Paired release procedures require checking the actual packaged build before tagging and exclude macOS metadata. Further content still needs a fresh budget check.

Passed TypeScript, all 50 tests, content/media/reference validation, unchanged forecast history, the repository-root Worker build and positive/negative checks against the new/old archives. Six new visitor-data contracts cover every catalog record, source registry, event, gallery, regional acquisition choice and emitted string-table module. In-app Chromium checked Korean mobile details/source disclosure, the English desktop shared-image gallery and its independent original links, loaded community wiki facts, existing effect playback, and November calendar KO→EN state preservation. The affected 390px/1440px screens had no horizontal overflow. All four redirects parsed; the previous pumpkin full-image URL returned 301. [UI evidence](../../research/2026-10-31-deployment-ui/results.json).

Content totals remain 755 cosmetics and 905 image references across 509 appearances. Existing large-chunk/framework warnings and the verification limits in v0.3.16 remain. Physical devices, Firefox/WebKit, throttled networks, field performance and the 200 KB initial JavaScript target were not newly measured. Site publication is verified separately from GitHub release; v0.3.16’s published tag remains unchanged.
