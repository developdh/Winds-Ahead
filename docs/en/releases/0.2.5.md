# 0.2.5 — Official dates first and complete image framing

[한국어](../../ko/releases/0.2.5.md) · [Website](https://windsahead.com/ko/calendar) · [Image audit](../../research/2026-09-23-image-framing.json) · [Pull request #30](https://github.com/developdh/Winds-Ahead/pull/30)

Show all official roadmap dates before editorial estimates, with separate headings and a visible non-official label. An earlier forecast-window start can no longer put a forecast ahead of an official date. Dates, evidence, revision history and filter semantics are preserved.

Repair the framing of 132 existing official-poster images, including Sandveil Venom's clipped right border, while retaining the previous crop coordinates in the audit. Detail and quick-view photos use complete images; poster cards and gallery selectors preserve both figures. All 582 selectors use small uncropped previews instead of portrait crops. The gallery opens fitted to the screen, supports optional zoom with horizontal/vertical scrolling, and resets zoom when changing photos. Image areas remain stable across different proportions.

Validation: type checking, 38 domain/media tests, content validation and the production Worker build passed. In-app Chromium checks covered EN/KO, gallery geometry at 320/360/390/768/1024/1440 CSS px, fit/zoom, image navigation, keyboard arrows, close/focus restoration and roadmap grouping/filtering. Full images and selector aspect ratios are checked automatically; all 132 poster boundaries were visually compared in contact sheets. The 582 selector files total approximately 1.76 MB and load only where needed. Existing Vite configuration and bundle-size warnings remain. Firefox/WebKit, physical devices, network throttling and field performance were not measured.
