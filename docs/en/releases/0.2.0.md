# Winds Ahead v0.2.0

[한국어](../../ko/releases/0.2.0.md) · [Website](https://windsahead.com) · [Pull request](https://github.com/developdh/Winds-Ahead/pull/25)

Browse cosmetics by **how to obtain them**, independently of release-server filtering and date/name sorting. This update also corrects the Forged in Fire gallery and incorporates the September 14 official Global appearance announcement.

## Changes

- Choose Shop, Resonance/draws, Sound Jade Shop, Battle Pass, Events, Gameplay/milestones, Other exchanges or Source unverified. Combine these with regional release filters and sorting; language changes and detail popups preserve the selection. Card prices use the same server as the filter.
- Correct the mixed identity in **Forged in Fire / 불길에 단련된 철골**. Its flame-helmet armor and Global terms are now separate from the unrelated CN red-cloth outfit. Previous evidence is preserved.
- Add eight official Korean names, including **찬 물결**, **무생의 독충**, **천수관음** and **허공의 물결**, plus six newly confirmed English names. Old Korean readings remain searchable.
- Add six Global September 16 announcements and update the two already recorded. All eight remain scheduled, with source-specific timing and unknown Global prices preserved.
- Add three distinct optimized reference images. The archive now contains **686 records and 557 photos across 371 appearances**.

## Validation and limits

Type checks, all **36 domain/media tests**, content validation, forecast-history preservation and the production build passed. Browser checks covered EN/KO filter combinations, sorting, empty-state reset, language changes, popup close/reload, old-name search and the corrected Forged in Fire image. Layout measurements covered 320, 360, 390, 768, 1024 and 1440px without horizontal overflow; filter controls retained 44px height. Mobile and desktop screenshots were inspected in the Codex in-app Chromium browser.

Physical-device, Firefox/WebKit and throttled-network/field-performance checks were not performed for this update. Existing large-chunk build warnings remain. This is a scoped review of the fresh Global announcement, not exhaustive X coverage. Unknown prices, actual release confirmation and image redistribution permission remain unknown.
