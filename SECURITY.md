# Security · 보안 제보

## English

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/developdh/Winds-Ahead/security/advisories/new). Include the affected revision, reproduction steps, expected impact and a minimal example. Do not put live tokens, account data or exploitable details in public issues. Normal data corrections belong in the issue tracker.

The maintained branch is `main`; historical research branches and old preview versions do not receive separate security backports. Response times are best effort for a volunteer project, not a guaranteed service level. Dependency and secret scans are checks, not a claim that the application is free of vulnerabilities. Refer to the current [release review](docs/en/public-launch.md) for known limits.

## 한국어

취약점은 [GitHub 비공개 보안 제보](https://github.com/developdh/Winds-Ahead/security/advisories/new)로 보내주세요. 영향받는 버전·재현 단계·영향·최소 예시를 포함하고 실제 토큰·계정 정보·악용 가능한 세부 사항을 공개 이슈에 적지 마세요. 일반적인 정보 수정은 이슈를 이용합니다.

유지보수 대상은 `main`이며 과거 연구 브랜치와 미리보기 버전에는 별도 보안 패치를 제공하지 않습니다. 자원봉사 프로젝트로 응답 기한을 보장하지 않습니다. 의존성·비밀키 검사는 취약점이 전혀 없다는 보장이 아닙니다. 알려진 제한은 [출시 검토](docs/ko/public-launch.md)에 기록합니다.
